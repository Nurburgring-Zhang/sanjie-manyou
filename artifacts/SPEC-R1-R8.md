## R1 河要有头有尾，水上有多种通道
- **问题**：城内河只在中段有水，桥外两侧断成沙地；河上只有一座桥，船无处可走。
- **要求**：河从城墙一端贯穿到另一端（两端出城/入护城河）；河上除主桥外再加 **2–3 座次级桥/浮桥/渡口**；船要能沿河行驶（有航道与数量）。
- **判定**：沿河中线每 100m 采样，水域覆盖率 ≥95%；桥/渡口数量 ≥3；船实例 ≥12 且沿河分布（不是只聚在桥下）。

## R2 河岸商业区与居民区之间不得有大片空地
- **问题**：临河商业带与里坊之间有一条宽 100m+ 的裸地。
- **要求**：商业带与里坊直接咬合（间隔 ≤12m），中间只允许巷道。
- **判定**：沿河两岸各取 20 条垂线，量"最后一栋临河建筑 → 第一栋里坊建筑"的空隙，p90 ≤ 12m。

## R3 河两岸商业带要覆盖全城河段
- **问题**：商业带只覆盖桥附近一小段。
- **要求**：从 x=−4800 到 +4800 的两岸都要有连续铺面（可分段、可疏密变化，但不能空段 >120m）。
- **判定**：按 200m 一段统计每段临河商业建筑数，连续空段 ≤1 段且总长 ≤120m。

## R4 皇宫要像故宫一样宏大精美，且必须在市区内部
- **问题**：宫城建筑简陋、体量小；且位置在城市中轴之外（用户在图上看到宫城在城外）。
- **要求**：宫城落在**城区内**（中轴线上，位于里坊包围中）；按故宫格局补：午门→太和门→三大殿（含重檐庑殿、三层台基、汉白玉栏板）→东西六宫→角楼；**内部**要有宝座、屏风、香炉、灯、地毯、陈设。
- **判定**：机检——宫城中轴 z 坐标在 ±5000 内且四周 300m 内有里坊；三大殿檐口高 ≥ 22m、台基 ≥3 层；室内陈设件数 ≥ 200（按 kit 计）。

## R5 皇宫前后大路要有繁华商业群与人群
- **问题**：宫前御街只有路，两侧空。
- **要求**：宫前/宫后各 ≥400m 的路段两侧要有连续商铺（密度与河岸商业带同档），人流 ≥ 120 人在该段活动。
- **判定**：该两段内临街铺面 ≥ 60 间；`crowd` 在该矩形内人数 ≥ 120（运行时统计）。

## R6 凌霄宝殿恢弘壮丽不足
- **要求**：在 R4 的审美标准下，宝殿再加一层（三重檐）、加高台基与栏板、加金顶层次。
- **判定**：檐口标高差 ≥3 层；殿身高度/岛半径 ≥0.30；`three-view/lingxiao-front.png` 需同时看到 ≥3 条檐口线。

## R7 附身/灵魂模式按键方向相反
- **要求**：两种模式（`soul` 相机 / `avatar` 附身）下 W/S/A/D 的前后左右必须一致；不得出现"灵魂态正常、附身态反向"。
- **判定**：探针分别设 `player.mode='soul'|'avatar'`，按 W 1.2s，比较位移与相机朝向的点积，两者同号且 >0.8。
- **状态**：✅ 已修（lead 单人）。根因 `player.toggleMode()` 进附身态时 `camYaw = actor.yaw + Math.PI`，移动方向由 `camYaw` 推导 → 相机与朝向差 180°，按 W 倒退。改为 `camYaw = actor.yaw`。`probe-move` 实测：附身态位移 4.14m、**点积 1.000**（修复前为负）；灵魂态 W 驱动相机而非化身，位移为 0 属预期。
