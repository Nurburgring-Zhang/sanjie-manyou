# F7 · 11-03 视觉遗留四条收口 spec（2026-11-04 立项 · 审核 B 指出的挂靠缺口）

## F7-1 贴脸深色屋面（一次遮挡性错误，未定位）

- **现象**：瑶池水榭近景（`_B5/court_close.png` 机位），前景有一块贴脸深色屋面遮挡主体。
- **定位手段**：从该机位打射线（`probe-camera-clearance.mjs` 已有同类机位清障先例），取首个命中的 mesh 的 b.kit 台账名与世界坐标；台账会直接给出归属系统。
- **修复判据**：`probe-camera-clearance` 扩一条「court_close 机位首命中距相机 ≥8m」断言；或该 mesh 落位修正后复拍前后对比图。
- **预算**：净增三角面 0（只允许挪位/删除，不许加件）。

## F7-2 远景发灰余雾（emissive 只解决约 4/255，剩下在雾里）

- **现象**：远景街面整体发灰；11-03 已把夜 emissive 提升 4/255，剩余灰度来自雾参数。
- **判据**（机检）：同机位（c_air 高空）取 300–800m 距离带 tier3 体块像素，**去雾校正后远近色相差 ≤15° 且明度落差 ≤ 当前期望值**；探针口径沿用 11-03 v2 修订后的 A1' 判据（禁用"发不发灰"的目测话术）。
- **修复方向**：`palette.ts` / `world.ts` 雾色与雾密度曲线按距离带分段（近带保和、远带压灰），不动几何。
- **预算**：净增 0；只许调雾与材质参数。

## F7-3 云海贴地档时序不稳定（同机位两次读 opacity 0.0102 / 1）

- **现象**：云海低档材质透明度在两次探针读数间跳变 100 倍——时序/帧相位依赖。
- **判据**（机检）：新探针或扩 `probe-cloudsea.mjs`：同机位连续 60 帧采样云池材质 opacity，**极差 ≤0.05 且均值 ∈ [设计区间]**；两次独立运行读数差 ≤0.02。
- **修复方向**：`expansion.ts` 云海贴地档的透明度驱动查帧相位依赖（大概率是按未锁 dt 的累计相位或材质共享被别处覆写）。
- **预算**：净增 0。

## F7-4 环形门实心盘（probe-round-gate 环心穿透失败：射线 378.7m 命中，环在 380m）

- **现象**：天宫环形门应是可穿过的环，环心射线在 378.7m 被截——几何把环心封死。
- **判据**：`probe-round-gate.mjs` 既有断言（环心射线应穿透到 ≥380m+）转红→绿即收口；补三向射线（环心/±45°）全过。
- **修复方向**：定位环形门几何的封心面（fan 三角化或盖板 b.kit 件），删盖或改环带三角化。
- **预算**：净增 0（只删不加）。
