# SPEC · R13 / R14（河中路面 / 皇宫空旷）

## R13 河上有路 = 不正常

**判断：不正常。** 河床里不能有通行路面。合法过河方式只有：**桥、浮桥、渡口（斜坡码头 + 系船石，不铺成车行路面）**；沿岸只允许 **2.5–4m 纤道**，高于水面 0.35m、材料为夯土/碎石、**不接车行道**。

**截图现象**（用户第 1 张）：桥东侧有一条与桥面同色的宽路带**直接铺进水面**，另有一道与岸平行的浅色带横跨河面 —— 读成"河里修了路"。

**排查顺序**（不要猜）：
1. `city/buildings.ts` 的 `buildBridgePlaza`：铺装矩形 x 34–420 / |z| 38–300，**y=0.22**；主河水面 y=1.0 —— 铺装应在水下，但若某段河宽收窄/岸线内缩，铺装会露出水面读成"路"。用 `probe-groundtrace` 查 x∈[30,300]、|z|∈[30,80] 的 ground 构件实际 y。
2. `city/riverbank.ts`：铺面从 |z|=40 起，若河宽 62m（半宽 31）则 40 太近，码头/台阶可能铺到水缘。
3. `city/river.ts` 的驳岸与码头：检查是否有 `ground` 组平台伸入水面。
4. `city/water.ts`（R10）支渠跨路石桥：确认是桥体不是路基。

**判定**：沿河每 50m 取垂线，**水面范围内不得存在 y>0.6 的 `ground`/`ash` 组盒体**（桥面除外，桥必须在 `roof`/`wood` 组且有栏杆）。纤道连续率 ≥90% 且不接车行道。

## R14 皇宫空旷 = 不正常

**判断：不正常。** 故宫的宏大来自**围合**：三面庑房/值房连成廊，广场两侧有门、有墙、有树、有陈设（铜鼎、日晷、嘉量、品级山），人流密集。现在三殿立在整片沙地上，两侧空空 —— 那不是故宫，是"三个模型摆在操场上"。

**必须补**（`city/imperial.ts`）：
1. **广场围合**：太和门→太和殿之间广场东西两侧各加 **9–13 间庑房**（进深 8–10m、面阔 6–8m、连廊相接），形成"廊庑夹道"；
2. **广场铺装**：御道 + 两侧**金砖铺装**（0.06m 厚，色 0x6e6a66），不要让沙地裸着；
3. **陈设**：铜鼎 4、日晷 1、嘉量 1、品级山 2 列（各 8 座）；
4. **树木**：广场四角各 3–4 株松柏（`sphere('leaf')` + `cyl('trunk')`，不要圆锥）；
5. **值房/朝房**：午门内东西各一排 6 间；
6. **人流**：广场内 ≥80 人（朝臣候朝、内侍执役、禁军巡守）。

**判定**：
- 三大殿之间广场两侧的庑房间数 ≥18；
- 广场内 `ground` 铺装覆盖率 ≥85%（无裸沙）；
- 陈设 kit 数：铜鼎 4 / 日晷 1 / 嘉量 1 / 品级山 16；
- 广场矩形内角色 ≥80 且出现 `serve`/`guard`/`court` 类行为。
