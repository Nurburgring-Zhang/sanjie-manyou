## 一、Design Brief（玩家承诺）

**一句话**：你是汴京城里唯一能穿三界的人——在《清明上河图》的赛博重绘里行走，用一个时辰的脚力，换一段能写进图鉴的三界见闻。

| 项 | 决策 |
|---|---|
| 目标手感 | 「压得住、看得远」：步行有重量（起停 ~0.25s），飞行有惯性，镜头稳 |
| 主动词 | **行走/飞行 + 交互**（靠近 → 提示 → 触发） |
| 副动词 | 传送（云路）、查看图鉴、切换昼夜、观看名场面 |
| 5–30 秒重复什么 | 走到下一个地标 → 触发际遇 → 拿到一条图鉴 |
| 1–5 分钟变化什么 | 时辰推进（昼→昏→夜）；解锁新的云路节点；遇到第一个「打不过要躲」的对手 |
| 怎么失败 | 被界域威胁击退（鬼潮/天兵/巨灵神），本次际遇进度清零，退回最近恢复点 |
| 怎么重开 | ≤3 秒：原地复活或跳回恢复点，不重新载入世界 |
| 奖励什么 | 图鉴条目 / 云路节点 / 一次性仙术（可重复使用的小能力） |
| 风险是什么 | 夜里威胁更强（同屏敌人更多、视野更差），但夜里的图鉴条目更稀有 |
| 高手多做哪一步 | 卡在「黄昏」窗口抢稀有际遇；用飞行绕开地面威胁直达高价值地标 |
| 本切片非目标 | 不做多人、不做装备树、不做长线养成 |

## 二、Core Loop 契约

> 玩家用 **漫游 + 交互** 达成 **收录图鉴 / 解锁云路**，同时 **时辰流逝与界域威胁** 制造风险；
> 成功给 **图鉴条目 + 云路节点 + 仙术**，失败造成 **被击退回恢复点、本次际遇进度清零**。

逐条落到代码：

| 契约条款 | 落地位置（现状 / 待建） |
|---|---|
| 动词映射到真实输入 | ✅ `game/player.ts`（WASD/空格/Shift）、触屏 `#stick` + `#lookzone` |
| 目标在 HUD 或世界里可见 | 🟡 HUD 有 POI 名称与距离；**缺「当前目标」一行**（待建：`ui/hud.ts` 增加 objective 行） |
| 压力在第一分钟出现 | 🔴 待建：首个遭遇（见下） |
| 奖励改变状态 | 🟡 图鉴条目已入 `heroEntries()`；**待建**：解锁云路节点写回 `POIS` |
| 失败教会玩家 | 🔴 待建：击退时 toast 写清「被什么击退、损失了什么」 |
| 重开足够快 | 🔴 待建：恢复点数组 + 3s 内复位 |

## 三、首个遭遇计划（天宫擂台 · 巨灵神）

**空间格式**：天宫 arena（`SkyCenters.arena`，半径 ~46m 的圆形石台），四面栏杆，中央无遮挡；相机在第三人称肩后，能同时看到 Boss 与两侧退路。

**相机能看见**：Boss 全身（高约 9m）、前摇抬臂、地面裂缝预警圈；看不见台下的云海（避免误判坠落）。

**玩家起点 / 首个决策 / 首个威胁 / 首个奖励**
- 起点：擂台南缘（传送落点），距 Boss 34m。
- 首个决策：正面压上（吃一次横扫但抢到破绽）还是绕侧（多花 6 秒但安全）。
- 首个威胁：巨灵神横扫（前摇 0.9s，地面出 140° 扇形预警）。
- 首个奖励：打赢 → 图鉴「巨灵神」+ 云路节点「斗率宫」解锁。

**地标**：四角石灯（亮 = 阶段 1，转红 = 阶段 2）。

**每 20–60 秒升级**：
- 0–45s（阶段 1）：横扫 + 踏地；HP 320，玩家单击 10 伤害。
- 45s 起（阶段 2，HP ≤50%）：加入「抓取」（前摇 1.2s，命中把玩家摔出台缘 → 回南天门恢复点）；攻击间隔从 3.2s 缩到 2.4s。

**恢复点**：天宫南天门（`POIS['nantian']`），失败后 3s 内复位，Boss 血量重置。

**危险预警**：扇形/圆形地面贴地光环（`vfx.ring`）+ 低频轰鸣（`sfx:drum`）+ 抬臂动画三者同时出现。

**模块化**：Boss 数值（HP/伤害/前摇/间隔/阶段阈值）全部走 `data/boss.ts` 常量表，便于第二个 Boss 复用同一状态机。

**验收（必须先写测试再实现）**
```
node scripts/probe-boss.mjs
# 断言：1) 真实输入能造成伤害，HP 单调下降
#       2) HP 跨 50% 时阶段从 1 跳到 2（HUD 文案与石灯颜色同步）
#       3) HP 归零 → victory 标志置真 + 图鉴条目 +1 + 云路节点解锁
#       4) 失败复位后 HP 回到 320、玩家坐标等于恢复点
```
