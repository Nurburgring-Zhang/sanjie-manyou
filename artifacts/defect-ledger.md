## E. 验证纪律

1. 每改一轮：`npx tsc --noEmit` → `npx vite build` → `node scripts/three-view.mjs <poi...>` → 看**原图**（不要只看缩略）→ `node scripts/png-stats.mjs` 量灰度。
2. 每个 POI 三视角（front / side / top）；top 半径按主体尺度放大，避免扎进屋顶。
3. 全量回归：`bash scripts/integrate.sh`（tsc / vitest / build / 19 机位 / 总览 / 差异表）。
4. 不允许用「代码上应该没问题」代替出图。
