# 追加给工作流 P（R12-D 天宫 / 地府人口）

用户追加原话：「天宫、地府也要有很多角色啊」

## 现状
- 天宫：`sky/deities.ts` 有 36 尊石像与若干神佛化身影，`sky/havoc.ts` 有 22 天兵 + 5 悟空分身（演出用），整体**天宫可见角色不到 100**。
- 地府：`sky/underworld.ts` 的 `spawnUnderworldCast` / `spawnGhostSprawl` 有鬼魂，但**分布稀疏、行为单一**。
- 三界共用 `MAX_HUMANS` 池（当前 1600，R12 要扩到 4800）。

## 目标（都在同一池内分配，不额外加）

| 界域 | 最低人数 | 角色类型 | 专属行为 |
|---|---|---|---|
| **天宫** | **≥300** | 仙官、天兵、力士、侍女、乐工、星宿随侍 | 巡天（沿云路往返）、奏乐（立于廊下）、侍立（殿门）、炼丹（丹房）、读经、驾云（缓慢横移） |
| **地府** | **≥400** | 鬼卒、判官、鬼魂、牛头马面、孟婆、押解队 | 押解（成队行进）、受刑（狱前跪伏）、排队过桥（奈何桥单向队列）、喝汤（孟婆庄聚集）、游荡（丰都街随机漫步）、哭诉（望乡台） |

## 分布要求
- **天宫**：凌霄殿前广场 ≥60、瑶池 ≥40、三环群岛每岛 ≥3、南天门 ≥20（守将+天兵）；
- **地府**：丰都街 ≥120（含摊主与鬼客）、阎罗殿 ≥50、奈何桥 ≥40（单向队列）、十八狱环每狱 ≥8、孟婆庄 ≥30、望乡台 ≥20。

## 判定（机检）
1. `sky`（y>120）角色数 ≥300，且行为种类 ≥5；
2. `hell`（y<−100）角色数 ≥400，且行为种类 ≥5；
3. 上述每个子区域达到各自最低人数；
4. 三界人数之和 ≤ 池容量（不许溢出；池溢出会静默打断初始化）。

## 约束
只改 `src/actors/crowd.ts`、`pools.ts`、`behaviors.ts`；天宫/地府的**落点坐标**可从 `sky/deities.ts`、`sky/underworld.ts` 只读导入，**不得修改这两个文件**；禁止 build / 打包 / `release-*`。
