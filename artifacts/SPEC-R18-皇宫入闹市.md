# SPEC · R18 皇宫为什么还没进闹市区

## 事实核对（不辩解）

上一轮（工作流 N）做的是：**宫城北墙从 z=−4450 内收到 −4000**，纵深 1500→1050m，门线（午门 z≈−2950）**没动**。

结果：
- 宫城仍在**城市北缘**：北墙到北城墙还有 **1000m 空带**；
- 宫城东西两侧 3900m 到城墙，两侧是坊，但**贴着宫墙的第一圈仍是空的**；
- 宫前御街两侧是保留带裸铺装（R15-B 正在填，但只从 z=−2900 往南）。

所以你的判断成立：**它只是"缩了一点"，没有"进闹市"**。

## 两条可选路线（必须选一条，不能糊）

### 路线 A：把宫城整体南移（推荐）
- 宫城 z 从 −4000…−2950 **移到 −2600…−1550**（纵深 1050 不变）；
- 这样宫城北侧 2400m、南侧 1550m、东西各 3900m 全是坊——**四面包围**；
- 代价：御街、宣德門前牌坊、州桥、虹桥的相对关系要跟着断言（它们是固定 landmark），需要重排中轴序列；
- 判定：宫城矩形外 300m 环带内 **坊数 ≥12**（现在北侧 0）。

### 路线 B：原地不动，把北侧与东西贴墙圈填满
- 北侧 z −5000…−4000 由空带改为**密集市集 + 民居**（约 1000×10000m 的带，够放 300+ 院）；
- 宫墙东西两侧贴墙 200m 内补**值房/库房/仓场 + 商铺排**；
- 代价：北侧本来是"城北空地"的设计（艮岳/校场），填满会失去那片开敞；
- 判定：北带建筑覆盖率 ≥45%，宫墙贴墙 200m 内建筑 ≥120 间。

## 结论

**走路线 A**——用户要的是"皇宫在闹市中间"，缩北墙解决不了，必须整体南移。路线 B 是妥协方案，会牺牲城北的开敞。
