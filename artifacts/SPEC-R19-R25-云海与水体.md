## R19 · 横贯地平线的黑带 / 天上黑洞

**状态**：🟡 已消除黑带，云海质感待重做（agent-274）

### 根因（已证）

`src/sky/expansion.ts` 的云海淡出机制（`buildCloudSeaView` / `CloudSeaHandle.setViewerY` / `cloudSeaOpacityAt`）
代码完整，但**全仓 grep 只有定义、没有调用**——从来没接线。后果：

- 云海盘（从 `city_fabric` 里按重心 y ∈ [CLOUD_SEA_Y_MIN, CLOUD_SEA_Y_MAX] 切出的 6–10 层同心盘）
  在任何高度都是满不透明；
- 站在地面（y=14）时，云海盘在 190m 高度、半径远大于可视范围，被读成**横贯地平线的一条黑带**；
- 站在它下方仰视时读成**天上的巨大黑洞**。

### 判据（已过）

```
PREVIEW_URL=http://localhost:4180/ node scripts/_multishot.mjs <dir> \
  '[{"name":"street","p":[0,14,2400],"t":[0,30,-2000]}]'
```

改前：地平线上方一条深褐黑带。改后：干净紫金天幕，天宫浮在天空、宫殿群可辨。

### 已接线（`src/world.ts`）

```ts
private cloudSea: CloudSeaHandle | null = null;
// 加载末尾，compactStatic() 之后（必须之后：切分对象是合批后的整块几何）
this.cloudSea = buildCloudSeaView(scene);
// update() 内，近景云海可见性判定的下一行
this.cloudSea?.setViewerY(this.engine.camera.position.y);
```

### 剩余（agent-274）

- 云海读成"灰绿脏水塘"：无顶光、无亮度层次、边缘硬圆边被读成湖岸；
- 天宫体量相对云盘过小；
- 有几条**白色长条漏光**从殿宇斜射出去（疑 `MeshBasicMaterial({toneMapped:false})` 的发光细长几何）。

## R20 · 城市中央的巨型蓝灰圆盘

**状态**：🔴 未修（agent-273 处理地形水体部分）

### 根因（已证，两个独立缺陷叠在一起）

**① 云海盘把整座城盖住了（主因，最严重）**

云海盘在 y≈190 铺开，**半径覆盖全城**。相机在 y ∈ (90, 1200) 之间飞行时，看到的"地面"
其实是云海盘的上表面——于是整座城读成一片**深绿/深蓝的大湖**。

证据：
- 隐藏 `cloudSeaGroup` 后同机位复拍，城市立刻完整出现（密到屋顶连着屋顶，御街、廊柱、宫墙全在）。
- 命令：`node scripts/shot-hide.mjs /tmp/cs_off.png 0 320 -400 0 20 -1500 cloudSeaGroup`
  → `hidden 1`，三角面 34.9M → 18.4M。

这同时解释了用户的三条抱怨：「地上的深绿色或者深蓝色，是河是湖？？？头尾呢」
「远处的巨大黑洞又是什么」「远处的巨大黑洞」。

**修法方向**：云海盘必须**局部化**（以天宫为中心，半径收到 800–900m），
并且**半透明 + 有孔隙**，让城市能透出来；不再是一块覆盖 3.5km 的不透明平盘。

**② 地形水体是一张死平涂盘（次因）**

`src/world/terrain.ts:812`：

```ts
const wm = new THREE.MeshBasicMaterial({ color: 0x1a5a70, transparent: true, opacity: 0.88, toneMapped: false });
// RIVERS：每段 PlaneGeometry；LAKES：CircleGeometry(1, 26) 缩放成 rx*0.94 × rz*0.94
```

实测台账（遍历 scene 拿包围球）：

| 数量 | 颜色 | 半径（m） | 中心 y | 材质 |
|---|---|---|---|---|
| 11 | `#1a5a70` | 1313 / 1489 / 1661 / 1753 / 1991 / 2154 / 2179 / 2374 / 2435 / 3053 / **3577** | 0 | `MeshBasicMaterial`，opacity 0.88，toneMapped:false |

问题：不吃光、不吃雾、不吃色调映射 → 任何时段同一块死蓝；湖只有 26 段，半径 3500m 时
相邻顶点间距 ~840m，边缘是肉眼可辨的多边形折线；没有岸线、没有深浅、没有波纹。

**这是用户说的「巨大的蓝灰圆盘 / 是河是湖？头尾呢」。**
