# SPEC · 位置合理性判据族（2026-11-02 建立）

> **为什么建这一族**：此前 18 项判据全在查"某个构件自己长得对不对"（有没有屋顶、瓦垄够不够、面数超没超），
> **没有一项查"它是不是被放在了该在的地方"**。结果连续三件事都是靠用户看截图骂出来的：
> 房子盖到河面上、11 个人站在水面、院墙穿房、门口贴一块大灰板、屋顶斜插白板。
> 这一类错误不会被"单个构件正确性"判据捕获，必须单独成族。

## 二、待建（按优先级）

### P1 `probe-road-clash.mjs` —— 建筑压在道路上

**要查什么**：任意有占地体积的构件，其 OBB 与「道路中心线 ± 路宽/2」相交即算冲突。
**豁免**：桥、牌坊、路缘石、门楼（跨街合法）、摊位（在人行道上合法）。
**阈值**：冲突件 **= 0**。
**用法**：`roadBlocked(x,z)`（`city/imperial.ts`）已能判"该点是否在路面上"，直接复用真源，不要复制折线。
**这条能一次抓住**「河边商业街的路上还有房子」这类问题的所有同族实例。

### P2 `probe-bbox-escape.mjs` —— 构件超出自身包围盒

**要查什么**：屋面单元、屋顶饰件、幌子等**有标称尺寸**的构件，实际顶点是否超出标称包围盒。
**阈值**：越界 >1.5m 的实例 **= 0**；同时统计**面法线朝下**的三角面数（翻面）。
**这条能抓住**「屋顶斜插出白板」——agent-330 正在做临时版，要做成常驻探针。

### P3 `probe-float-bury.mjs` —— 悬空与埋没

**要查什么**：
- **悬空**：构件底面高于其正下方地面 >2m，且其下方 3m 内没有任何支撑构件（排除浮岛、灯笼、匾额、吊灯、飞檐）；
- **埋没**：构件顶面低于其正下方地面（整件埋进土里）。
**阈值**：两类都 **= 0**（白名单之外的）。
**难点**：白名单要写细，否则误报一片（灯笼、幌子、檐口、栏杆、云、船、鸟全都合法悬空）。
**建议先只做"埋没"**——那个几乎无歧义。

### P4 `probe-facade-clean.mjs` —— 立面上的异形贴片

**要查什么**：贴在建筑立面上的四边形，若其面积 >6㎡ 且材质为 `wall`/`lacquer` 的深色、且四周无框无依附 → 报"可疑大色块"。
**阈值**：可疑块 **= 0**。
**这条对应**「太和门匾额下一块大灰板 + 两侧悬空黄方块」。

## 三、执行纪律（写进每个 agent 的指令）

1. **任何"数量多、随机放置"的系统**（院落、树木、摊位、船只、幌子）在合入前必须过 P1/P2 两道；
2. **任何"有标称尺寸"的构件族**（屋面单元、门窗、匾额、旗幡）必须过 P2；
3. 探针里**硬编码的几何假设**（尺寸带、中心坐标、半径上限）必须配一条「命中数 > 0」自检——
   天宫的 ×2.2 缩放已经因此坑过两次（4.3 侧墙带、4.1 centers 未换算）；
4. 判据只认**机检数字**，不认"我看图觉得好了"。

## 四、失败案例留档（防止再犯）

| 事件 | 漏在哪 |
|---|---|

| 院墙穿房（12,667 段） | 没有 P1/P2；摆位各自独立计算，从未做过相互干涉检测 |
| 太和门大灰板 + 悬空黄块 | 没有 P4 |
| 屋顶斜插白板（三界都有） | 没有 P2 |
| 河边长条破坏"两排+街" | 没有**格局契约**——见下 |

### 第五条需要新增一类：**格局契约**（layout contract）

「两排建筑 + 中间一条街」这类**组合关系**不属于上面任何一条。要单独定义：
沿某轴线每隔 N 米取断面，统计**两侧各有多少铺面、中间街宽多少**，
一段里两侧都 <1 或街宽 <4m 即判"格局破坏"。
`riverbank.ts` / `centralbelt.ts` 的验收就应该是这条（agent-328 正在做临时版）。

## P2 探针已落地（`scripts/probe-bbox-escape.mjs`），但**判据还需一轮收敛**

已写好并跑通：逐**几何**检查本地包围盒是否超出标称单位盒（`x/z ∈ ±0.75`、`y ∈ [−0.15, 1.45]`），
以及「面法线朝下」的三角面占比。

**为什么逐几何而不是逐实例**：屋面类几何是"按单位足迹建好、再按实例缩放摆位"的，
几何自身越界会被每个实例按自己的尺寸放大——所以查一次几何即可，结论与实例无关。

### 实测发现 6 个命中，但其中有**已确认的误报**

- `heavenMist`（180 面，bbox ±0.979，`downFacingRatio 0.256`）——那是**云团球体**，不是屋面。
  球体天然有约一半面朝下，用"朝下占比"判翻面对它完全不适用。
  ⇒ **翻面判据只能用于屋面类几何，不能用于闭合体/球体**。

### 需要修的两处判据缺陷（下一轮做）

1. **先按几何族分类再判**：只对 `roof/gable/tent/shed/thatch/blockroof/gwall/slab/eave` 这类"单坡/双坡屋面"做翻面检查；
   球体（云、树冠、灯罩）、圆柱（柱、鼓）一律排除。
2. **排除合批网格**：`city_*` 动辄数百万面，逐三角算法线会把渲染进程拖死（本轮实测直接崩掉一次，已加 `triCount > 200000` 与 `city_` 前缀跳过）。

### 本轮的价值与边界

- 价值：第一次有了"屋顶几何自身越界"的自动判据，不再只靠人眼看截图；
- 边界：**当前 6 个命中不能直接当作 6 个缺陷**——至少 `heavenMist` 是误报。
  在判据收敛前，这个探针只能用于**定位候选**，不能作为门禁，也不能对外报"修了 6 处"。
