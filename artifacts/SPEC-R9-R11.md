# SPEC · R9–R11（水系分支 / 湖泊 / 园林与游乐）

> 用户三问，先给判断，再给可执行口径。**判断依据是《清明上河图》与北宋汴京的实际水系**，不是"我觉得好看"。

## 一问：河中应该有路吗？

**不应该。** 河床里跑车走人是错的，且现在代码里确实有这种读感来源：
- `props.ts` 的 `ground.riverBed`（y=−2.4）是**河床底**，不是路；
- 但御街跨河处、以及沿河若干"石板直铺到水边"的段落，视觉上像"路伸进河里"。

**正确做法**（R9）：
1. 河床一律不铺装（保持水下暗色）；
2. 两岸各有一条 **2.5–4m 纤道（towpath）**，比水面高 0.35m，材料用夯土/碎石，**不接车行道**；
3. 车马过河**只能走桥/浮桥/渡口**；渡口处有斜坡码头 + 系船石，但**不铺成车行路面**；
4. 判定：沿河每 100m 采样，水面内不得出现 `ground` 组铺装盒（lam>0.35 的浅色板）；纤道在两岸连续率 ≥90%。

## 二问：应该有多条分支河、多个小湖随机分布吗？

**应该有，而且是"有章法"的分布，不是随机撒。** 汴京实际是**四河贯城**：汴河（漕运主脉，东西向）、蔡河（南北向，穿南城）、五丈河（东北向）、金水河（西北入宫城），另有**金明池**（皇家水军演练池，周长九里）与城内多处池沼。

**做法**（R10）：
1. 主河（汴河）保持现状；新增 **2 条支渠**：一条南北向（宽 18–26m，从主河分出后向南抵城墙内缘）、一条东北向（宽 12–18m）；
2. **3–5 处池沼**：直径 60–140m，落在坊间空地（不与建筑重叠），其中 1 处做成**大湖**（直径 ≥220m，带岛与桥）；
3. 每条支渠都要**有头有尾**（一端接主河或护城河，不能凭空断头）；
4. 判定：支渠数 ≥2、池沼 ≥3、大湖 1；每处水体边界闭合（首尾相接），与建筑最小间距 ≥8m。

## 三问：应该有多个大小公园/园林/游乐场所吗？

**必须有。** 汴京有**琼林苑、金明池、玉津园、宜春苑**四大皇家苑囿，城里还有大量寺观园林与私家宅园；市井娱乐则是**瓦舍勾栏**（说书、傀儡戏、杂剧、相扑）。

**做法**（R11）：
1. **大苑囿 2 处**（≥300×300m）：水面 + 岛 + 桥 + 亭台 + 成片乔木 + 曲径；
2. **中小园林 6–10 处**（60–150m）：一池一亭三树一石，散在各坊空地；
3. **瓦舍勾栏 4–6 处**：围栏场子 + 戏台 + 看棚 + 灯笼，配 crowd 锚点（说书/傀儡/相扑）；
4. 判定：苑囿 2、园林 6–10、瓦舍 4–6；每处有 `kit` 归因标签；园林/苑囿内乔木 ≥20 株。
