## 九、如实残留（未达成部分，不写成「已完成」）

1. **街道与里坊建筑的矩形骨架仍是规则网格**。本轮解决的是绿地轮廓与形状，没有重做城市生成器的街区拓扑；彻底去网格化需改 `src/city/buildings.ts` / `units.ts` 的布点算法，属下一轮工作。
2. 宫城中轴御道、三大殿丹陛广场按 `floraClear()` 保留灰白礼制铺装 —— 礼制广场，不是草地缺失。
3. 山顶 / 雪线裸岩按真实山岳保留，未强行铺满植被。
4. 黄昏光下草地整体偏深绿，是既有光照基调。
5. 单包 2.68 MB 触发 Vite 的 1600 kB 分块告警，不影响运行。
6. L3 代码档需用户自行配置 API key；未配置时自动降级 L1/L2，离线可用。
7. 许愿台造物状态**尚未接入存档持久化**，刷新页面后本次会话生成的实体会消失（`src/rt/save.ts` 的 `collectPersistedEntities` 已支持按 kind 收集，接线属下一轮）。
