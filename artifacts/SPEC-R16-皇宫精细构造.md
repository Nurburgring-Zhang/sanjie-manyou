# SPEC · R16 皇宫精细构造（雕梁画柱级）

> 用户截图（2026-11-01）：三大殿是**金色平板屋顶 + 红墙色块**，没有檐口线、没有斗栱、没有瓦垄、没有门窗、台基是一块白板。用户原话：「这么粗糙？？我要极端精致的高精度建模」。

## 诊断（对着截图逐项）

| 应有 | 截图实况 | 缺的构造 |
|---|---|---|
| 屋面瓦垄（筒瓦/板瓦条纹） | 一整片光滑金色斜面 | 无 `roofOn(rib=true)` 的顶点色瓦垄，也没有 eaveTrim 的瓦当/滴水 |
| 檐口 | 一条波浪边 | 无连檐 + 飞椽 + 椽头 + 滴水唇 |
| 斗栱 | 无 | 无 `dougongBand` |
| 柱子/额枋/雀替 | 无（只有红墙） | 无柱列、无额枋、无雀替、无彩画带 |
| 门窗 | 一排金色小点 | 无隔扇/槛窗/板门构造（`buildDetailedFacade` 已有但没被调用） |
| 台基 | 一块白板 | 无三层须弥座、无汉白玉栏板（望柱+寻杖+地栿）、无螭首 |
| 屋顶层次 | 单层曲面 | 重檐的两层檐口贴合、无垂脊/戗脊/走兽 |

**根因**：这一版是「体块优先」——用 `roofC` + `box` 堆出体量，**没有接项目里已有的精细子系统**（`roofOn`/`dougongBand`/`buildDetailedEave`/`buildDetailedFacade`）。而这些函数本来就是为这种尺度写的。

## R16 要求（每条都可机检）

### R16-A 屋面（每殿）
1. 用 `roofOn(..., rib=true)` 或等效：**瓦垄列数 ≥ 面阔/0.34**（200m 殿 → ≥500 列，受 `roofRibCols` 上限 768 约束），顶点色明暗交替；
2. 檐口三件套：连檐（0.3m）+ 飞椽头（每 0.6m）+ 瓦当/滴水（每 0.6m 一枚）；
3. 垂脊/戗脊：沿四条坡棱分段贴（每 2m 一段），脊端有**走兽 3 只**；
4. 正脊：高 0.9m，两端**鸱吻 1.8m**，脊心宝顶。

### R16-B 斗栱与柱列
1. 檐下**斗栱带**：每开间 2 攒，攒距 ≤3m，栱高 0.9–1.2m（用 `dougongBand`）；
2. 檐柱列：柱径 1.1m、柱高与檐口匹配、柱础 1.4m 见方、柱头有箍；
3. 额枋 + 雀替：额枋高 0.8m，雀替每柱两侧各一；
4. 和玺彩画带：额枋上青绿叠晕（用顶点色条纹，不要贴图）。

### R16-C 门窗（正立面）
1. 明间：**六抹隔扇 6 扇**（每扇 0.9×4.2m，含裙板/绦环板/棂心）；
2. 次间：**槛窗 4 扇** + 板壁；
3. 尽间：板壁 + 直棂窗 2；
4. 每扇隔扇的棂心格数 ≥12（横向 4 × 纵向 3）。

### R16-D 台基与栏板
1. 三层须弥座：每层高 1.55m、逐层收进 1.8m，束腰处有**椀花结带**（几何线脚）；
2. 汉白玉栏板：望柱每 2.4m 一根（柱头 0.5m）、栏板间**寻杖 + 地栿**两道、转角处**螭首**；
3. 御路：中间 8m 宽丹陛石（浮雕云龙抽象化：3 道弧形纹 + 6 处云头）、两侧踏步 12 级。

### R16-E 园亭楼阁台
1. 御花园内：**亭 4 座**（四角攒尖，宝顶 + 4 脊 + 坐凳栏）、**楼 2 座**（两层，腰檐 + 平座栏）、**台 1 座**（月台，带栏板与蹬道）；
2. 每座亭/楼要有：柱 4–8 根、额枋、斗栱带（简化 1 层）、瓦垄、坐凳栏。

### R16-F 室内（在 R14 的 248 件基础上加构造）
1. 殿内**藻井**：明间顶部 1 座（3 层叠涩 + 井心圆雕），次间平棊；
2. **金柱** 8 根（径 1.0m）+ 蟠龙柱 2 根（明间两侧）；
3. 地面：金砖（0.9m 方砖，纵横缝 + 中央御路石）；
4. 宝座区：宝座 + 屏风 + 地平 + 香亭 2 + 仙鹤 2 + 日晷 1 + 嘉量 1。

## 判定（机检，不接受"看着更细了"）

| 项 | 阈值 | 取数 |
|---|---|---|
| 瓦垄列数 | ≥500（200m 殿） | `roofRibCols` 实参 |
| 斗栱攒数 | ≥60（单殿正面） | kit `palace.bracket` |
| 隔扇/槛窗数 | ≥40（单殿正面） | kit `palace.door` / `palace.window` |
| 栏板望柱 | ≥80（单殿台基） | kit `palace.balustrade` |
| 走兽 | ≥12（三殿合计） | kit `palace.beast` |
| 亭/楼/台 | 4 / 2 / 1 | kit `palace.pavilion` 等 |
| 藻井 | ≥3（三殿各 1） | kit `palace.caisson` |

**出图**：午门内望太和殿、太和殿近景（≤30m）、台基转角 — 三张图里必须能数出**瓦垄、斗栱、隔扇、望柱**四类构造，否则判未完成。
