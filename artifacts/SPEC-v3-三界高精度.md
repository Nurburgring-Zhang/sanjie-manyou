## §8 新增硬约束（2026-10-29 用户追加，优先级最高）

> 用户原话：「普通百姓房子、道路、院落、小巷等，**严禁规整**，必须是**散落的、歪七扭八的、有大有小、随机的组合、密集的分布**的。」

这条**推翻**本轮 W2 的"正交坊格 + 等宽巷道 + 等距院落"方案。适用范围与例外：

| 对象 | 要求 |
|---|---|
| 百姓住宅 | 严禁对齐：朝向 ±14° 抖动、尺寸 3–20m 跨档、形制随机组合（一正两厢／一正一厢／仅院墙／L 形／三合院）、成组错落 |
| 院内 | 院子不成矩形：围墙折线、门位随机、院与院之间缝隙 0.8–4m |
| 小巷 | 严禁正交网格：走向随院落生长、宽 1.6–5.5m 随机、允许断头巷、允许斜穿 |
| 坊（街区） | 边界不是矩形：四角各 ±18m 抖动、边线略弯、坊内用**抖动二分**切地块而不是行列 |
| 道路 | 一般街巷随地块走；**御街（x=0 中轴）与城门大街**保留直线（它们是仪制轴线，不是百姓道路），其余大路允许 ±40m 横向游走 |
| 密度 | 建成覆盖 82–88%，不得为了"整齐"留白 |

**验收判据（可机检）**：
1. 抽样 200 个院落，`|cos(朝向)|` 的方差 > 0.02（不能全 0 或 1）。
2. 抽样 200 个院落，`w/h` 与 `w*d` 的面积分布覆盖 ≥4 个量级档（例如 <40㎡ / 40–90 / 90–200 / >200）。
3. 抽样 100 条巷，相邻两段夹角非 0/90° 的比例 > 60%。
4. 建成覆盖率 0.82–0.88。
