# 追加给工作流 P（R12-C 场所级人口覆盖）

用户追加原话：「居民区与皇宫、寺院等等其他场所也要有人啊」

问题：现在的人几乎都在街上与 POI，**里坊院内、寺院、宫城、瓦舍里是空的**。

## 要求（从总预算 4000–4500 里分配，不是额外加）

| 场所 | 最低人数 | 专属/主要行为 | 落点约束 |
|---|---|---|---|
| 每个里坊 `wardCell` | **≥6** | 家务（洗衣/打水/晾衣）、孩童追逐、坐门槛闲谈、择菜 | 院内与巷口，**不在街心** |
| 每处寺院/道观 | ≥8 | 上香/叩拜/扫洒/讲经/化缘 | 山门内外与殿前 |
| 宫城矩形 | **≥60** | 内侍执役、宫人穿行、禁军巡守、候朝 | 殿前广场/庑房/宫门 |
| 每处瓦舍勾栏 | ≥20 | 看戏、叫好、说书、相扑围观 | 场子内与看棚 |
| 河岸商业带 | 每 200m 段 ≥15 | 交易、卸货、吆喝 | 铺面前 |
| 码头/渡口 | 每处 ≥10 | 卸货、撑船、候船 | 岸边与栈桥 |

## 实现要点

- 里坊人数按 `wardCells()` **逐格**分配（可从 `imperial.ts` 只读导入）；
- 宫城/寺院用现有常量与 `POIS`（只读）；
- 每类场所必须有**专属行为**（`worship` / `guard` / `serve` / `watch_play`），不能全用街面的 walk/stand；
- `window.__crowd` 增加 `places: { wards, temples, palace, washe }` 与各项达标布尔。

## 判定（必须在 dev 上实测并写进交接）

1. 抽 20 个 `wardCell`，每格矩形内人数 ≥6；
2. 每个寺院 POI 半径 60m 内 ≥8 且出现 `worship`；
3. 宫城矩形内 ≥60 且出现 `guard`/`serve`；
4. 每处瓦舍 ≥20。

> 约束不变：只改 `src/actors/crowd.ts`、`pools.ts`、`behaviors.ts`；禁止 build / 打包 / 碰 `release-*`。
