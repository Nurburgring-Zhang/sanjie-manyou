# SPEC · R20 城市中央的「巨大蓝色圆盘」与无头尾的水线

> 用户截图（2026-11-01，距东洋巨泽 7061m 高空俯视）：城市中央有一个**直径约 700–900m 的深蓝灰色圆盘**；另有多条**细直深蓝线**横贯全城；整片地面是沙色网格，看不出'河'应有的带状形态。用户问：「是河是湖？？？头尾呢？」

## 必须先用测量确定它是什么（四个候选，各有判别法）

| 候选 | 判别法 |
|---|---|
| A. 地府冥土远景盘 `b.cyl('ground', 9000, 9000, 0.8, 36, 0, UNDER.y−1.6, 0, 0x150d13)`（`sky/fengduGround.ts:47`） | 隐藏 `city_ground` **不影响**它；它的世界 y ≈ −261.6。查 `scene` 里半径 ≥8000 的 mesh 的 `position.y` |
| B. 汴河 `riverRibbon` 水面在极远视角下被压缩成圆斑（透视/雾导致） | 隐藏 `city_water` 或 `river` 相关 mesh 后圆盘消失 |
| C. R10 支渠/池沼某处尺寸写错（应为 20–120m 却成了 700m+） | 用 `waterAudit()` / kit `water.branch|pond|lake` 的包围盒核对直径 |
| D. `buildBridgePlaza` 铺装或 `terrain` 的孔洞导致看到下方暗面 | 隐藏 `city_ground` / `terrain` 分别对比 |

**判别顺序**：先隐藏 `city_water`（B）→ 再查半径 ≥8000 的 mesh（A）→ 再读 water kit 包围盒（C）→ 最后 hide ground/terrain（D）。**必须给出「隐藏哪一组后圆盘消失」的结论，不接受推测。**

## 关于「头尾」

即使圆盘是 A/B/C/D 之一，用户的核心诉求仍成立：**水面必须读成带状并有两端收口**。R15-C（水关涵洞 + 闸门 + 水门楼）正在做，落地后：
- 汴河两端在 ±5000 处有水关实体（石拱、闸板、驳岸延伸）；
- 从高空俯视应能看出「一条贯穿的带 + 两端实体收口」，而不是"一摊水"。

## 同时要查的

1. 那几条**细直深蓝线**（约 5m 宽、贯穿全城）是什么：是 R10 支渠（宽应 15–20m，图上不像）、还是 `ground` 组的暗色分缝、还是 `river` 的岸线？用同样的隐藏-对照定死。
2. 高空俯视下**铺装完全看不到**（整片沙色）：`buildPavement` 的铺装是否只在近档 LOD 才可见？若是，远档需要至少一张"铺装色"贴地层。

## 判定

- 给出圆盘的**来源 mesh 名 + 世界 y + 直径**；
- 圆盘若属缺陷（B/D 类）→ 修掉；若是地府远景盘（A）→ 它不该在俯视时穿过地表可见，需加遮挡或下移；
- 高空俯视图必须能看出「河是带、湖是圆、两端有收口」三件事。
