# SPEC · R15 密度（河岸 / 御街 / 皇宫）—— 为什么"看起来还是空的"

> 用户截图（2026-11-01）：御街俯视 + 中轴长街。四条质问都是同一个病：**有铺装、没建筑；有单排、没纵深；有水面、没头尾**。

## 诊断（按截图事实，不猜）

| 现象 | 代码事实 | 结论 |
|---|---|---|
| 河边只有**一排**摊铺，后面是几百米裸铺装 | `riverbank.ts` 只从 `|z|=40` 起铺**一排**，进深 10–14m（到 |z|≈54 结束）；而 `buildBridgePlaza` 把 x 34–420 / |z| 38–300 全铺成砖 | 铺装面积 >> 建筑面积 → 读成"广场上摆了一排摊" |

| 皇宫内空旷 | R14 正在补庑房与陈设（进行中） | 等 R14 落地再看 |

## 修法（R15，按优先级）

### R15-A 河岸商业带改成「三进深成排」
- 从河沿起，**三排**铺面：
  - 第一排 |z| = 河半宽 + 6 … +6+12（临河铺面，已有）
  - 第二排 |z| = 第一排后 + 3m 巷道，进深 10–14m
  - 第三排 |z| = 第二排后 + 3m 巷道，进深 12–16m，**贴到里坊墙**
- 排与排之间留 3m 巷道，**纵向（沿河）错缝 30–60%**，不许对齐成三条平行线；
- 目标：临河 200m 段内建筑面积占该段可用地面 **≥55%**（当前约 12%）。

### R15-B 中央保留带（|x|<950）填实
- 御街两侧各 **2 排**铺面（临街排 + 后巷排），间距 8–20m、进深 10–14m；
- 保留带其余面积补：值房/仓库（6–8 间）、小院（带院墙）、行道树（每 12m 一株）、水井、牌坊；
- 目标：保留带内建筑投影覆盖率 **≥45%**（当前 <8%）。

### R15-C 河的两端收口
- 汴河两端在城墙内缘做**水关**：石砌涵洞（宽 = 河宽 ×0.6、高 4m）+ 闸门 + 两侧驳岸延伸；
- 御沟/金水河端头做**石雕龙头吐水口**或涵洞，不得平切消失；
- 判定：沿河中心线从 −5000 走到 +5000，**任一端 30m 内必须存在 kit 为 `water.culvert`/`water.head` 的收口构件**。

### R15-D 皇宫主道（R14 之后）
- 宫前御街与宫后街各补 2 排铺面（同 R15-B 参数）；
- 目标：这两段 400m 内临街铺面 **≥60 间**（R5 原口径）。

## 判定汇总（机检）

1. `riverbank` 排数 = 3，纵向错缝比例 ≥30%；
2. 临河 200m 段建筑面积占比 ≥55%（用 `__groundTrace` + 铺面 kit 包围盒估算）；
3. 中央保留带建筑覆盖率 ≥45%；
4. 河两端 30m 内存在 `water.culvert`/`water.head`；
5. 出图：御街俯视、河岸俯视、皇宫广场，三张图里**不得出现 >40m 的无建筑裸铺装**。
