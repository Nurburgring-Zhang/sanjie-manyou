## 0. 愿景与三大玩法支柱

**一句话**：在赛博风北宋汴京（人间）与天宫/地府三界中，玩家获得《我的世界》式的**预设空间/资源/合成/建造**能力与《孢子》式的**进化升级/造物/叙事**能力，并通过游戏内 Agent 实现任意造物愿望（"我要一条龙"→ 3–5 分钟内 agent coding 构建资产 → 热更新加载到玩家周围 100m）。

| 支柱 | 来源 | 本项目形态 | 详细卷 |
|---|---|---|---|
| 三界世界 | 既有成品 | 4,496 实体 / 19M 静态面 / 7 桥 6 形制 / 45,981 万帧三角的已成世界（人间+天宫 2150m+地府） | D1 D2 |
| MC 玩法 | 我的世界 | 体素沙盒（预设空间/资源/合成/建造）+ 生存循环 + 生物 | D3 |
| 孢子玩法 | 孢子 | 造物编辑器（八槽×十二件）+ 六道阶位进化 + 涌现叙事 | D4 |
| 造物链 | 原创核心 | **游戏内 Agent**（D5）+ 双 AI 议会（D6）：用户一句话 → agent coding → 沙箱校验 → CreationBundle 四门 → 资产热替换落场 | D5 D6 |
| UI/UX + 性能 | 既有 | HUD/建造交互/传送/附身；p95≤50 发布门 | D7 D9 D10 |

**覆盖度申报（诚实口径，清单 v3 R5）**：三界 0.8 / MC 0.06 / Spore 0.2——现有清单主体是「三界改造+造物链」，**MC 体素核心/合成/生存/生物/红石/多人（2,530 行 D3 + V4/V6/V8/V10/V12 卷）与 Spore 部件内容（缺 56 件）/业缘关系网仍在 P1/P2 段**，不是已建成部分。
