## 0 效力与读法

1. **代码为准。** 本文每个反引号里的数值都带 `文件:行号`。代码改了而本文没改，以代码为准，并视为本文的缺陷。找不到代码出处的，一律标 `待建`，不得当作已实现。
2. **冲突裁决顺序**：ADR > 本文 > `docs/assets/44-材质色彩总谱.md`。旧总谱与代码已漂移，§1.5 逐条列出，不得再作为取色依据。
3. **只写可判定的东西。** 写不出判据的条目，归入 §8 已知缺口，不写进规范正文。
4. **阈值分两类。** 带 `文件:行号` 的是代码既有常量；标【规】的是本文自定、代码里没有对应常量的判据阈值。两者都要机检，但【规】类在落地时由实现方补常量。

### 1.1 天宫（主色 12 + 派生 5 组）

### 1.6 色板使用纪律

1. **一语义一 hex。** 同一语义全项目只允许一个色值，差一级通道即算漂移。派生色只能由 `shade(基色, k)` 在线性空间生成（`src/city/bake.ts:570`），不得手写新的近似 hex。
2. **新增色必须三件套齐备**：语义名 + hex + 用途映射与禁止用法。缺任一项不得入库。
3. **跨组不共用色值不等于可以近似。** 例如屋面 `0x333a45` 与脊 `0x272d36` 是两个语义（瓦 / 脊），允许并存；但「另一种瓦灰」属于漂移，禁止——只要它不在 §1 的登记表里，哪怕只差一级通道。

判据：`probe-palette-drift`（待建）对每个材质组做顶点色直方图，出现未在 §1 登记且占比 >1% 的 hex 即报错。

## 2 材质规范（14 组）

14 个材质组是**封闭集合**：`wood / wall / roof / ash / earth / ground / glow / leaf / trunk / water / ceramic / metal / fabric / lacquer`（`src/city/bake.ts:4`）。ADR-8 明确规定「不许新建材质组（会破合批）」，新增材质只能在这 14 组里换色。

明度区间是该组在现有代码中实际使用色值的线性亮度范围（Rec.709），由 §1 色板实算，不是估计值。

| 组 | 渲染器与参数 | 粗糙度感觉 | 明度区间 | 允许用途 | 禁止用法 |
|---|---|---|---|---|---|
| `wood` | Standard，r `0.82`，m `0.03` | 干木，微哑，顺纹高光 | `0.038–0.113` | 柱、梁、枋、门扇、椽、栏杆、木地板 | **石作**（台基、栏板、须弥座）；屋面 |
| `wall` | Lambert + emissive `0x3a3d48` | 粉墙，全漫反射，无高光 | `0.602–0.777` | 夯土/砖墙面、山墙、院墙 | 承重柱、屋面、可触碰的台面 |
| `roof` | Standard，r `0.93`，m `0`，env `0.10` | 哑光瓦，只有贴图里的窄高光 | `0.026–0.125` | 瓦面、脊、瓦当、滴水、檐口封板 | 墙面、地面、任何垂直大面 |
| `ash` | Standard，r `0.95` | 石，粗糙，几乎无镜面 | `0.231–0.881` | 台基、石栏、御路、石雕、汉白玉 | 木构、瓦面、布幔 |
| `earth` | Standard，r `0.96` | 夯土，最粗糙一档 | `≈0.219` | 夯土墙芯、土台、田埂 | 精加工石面、室内地面 |
| `ground` | Standard，r `0.96` | 铺装，干、微尘 | `0.216–0.219` | 街面、广场、殿内金砖地坪 | 屋面、墙面 |
| `glow` | **Basic**，toneMapped | 无光照，像素即最终值 | 不走光照 | 灯芯、窗纸、匾额、神光、幡头 | **结构件**（柱/墙/台基）；单件 >0.5m² 的大面 |
| `leaf` | Lambert + emissive `0x16211a` | 叶面，半透感靠 emissive 模拟 | 由色值决定 | 树冠、灌木、花瓣簇 | 建筑任何部位 |
| `trunk` | Lambert + emissive `0x0a0806` | 树皮，极暗 | 极低 | 树干、枯枝、根 | 建筑构件 |
| `water` | **Basic**，opacity `0.85`，不 toneMap | 无镜面，只有色与透明 | 由色值决定 | 河面、池面、渠面 | 需要反射的「镜面地」（镜面地走 `ground` 深色抛光） |
| `ceramic` | Physical，r `0.42`，clearcoat `0.5` | 釉面，湿润，柔高光 | `≈0.865` | 花瓣、瓷器、琉璃小件 | 大面积墙面、屋面 |
| `metal` | Standard，r `0.52`，m `0.35`，env `0.4` | 金属，半哑，弱环境反射 | `0.021–0.432` | 金饰、铜件、门钉、铁箍、钟 | 结构承重件；大面积平涂金 |
| `fabric` | Physical，r `0.92`，sheen `0.25` | 布，柔，几乎不反光 | 由色值决定 | 幡、帐幔、旗、帘、衣 | 建筑面层、屋面 |
| `lacquer` | Physical，r `0.36`，clearcoat `0.85` | 大漆，湿润高光 | `≈0.015` | 漆柱、漆案、匾框、藻井 | 室外大面（会与天光打架） |

参数全部来自 `src/city/bake.ts:1468-1492`。三条硬约束：

1. **`glow` 不是「亮色」**，是「自发光」。判据是「这块面是否自己发光」，不是「这块面是否很亮」。栏杆、台基、柱身再亮也不许进 `glow`。
2. **`wood` 不得用于石作**。判据：构件若有收分、有雕凿、位于地面以上 `0–1.5m` 的承重基座，一律 `ash`。
3. **`metal` 与 `ceramic` 的环境反射必须压在阈值下**：`metal.metalness ≤ 0.4`、`envMapIntensity ≤ 0.5`、`ceramic.clearcoat ≤ 0.6`、`leaf.map > 0`（`scripts/probe-material.mjs:21`）。超了就会在掠射角整片返白，这是本项目「白色方块」的第二大来源。

## 3 比例规范

### 3.1 模数

- 基本尺：`0.32m` = 1 宋尺（`docs/重建-v2/00-重建纲领.md:98`）。
- 开间步长：`3.2m` = 10 宋尺（`src/city/buildings.ts:1016`，`Math.round((w - 1.4) / 3.2)`）。
- 层高：`floors * 3.2`（`src/city/buildings.ts:754`）。
- 对齐超单元：`8.0m`（0.32 与 0.5 的公倍数），`1.6m` 只是营造单元（纲领 `:98`）。

### 3.2 柱

| 项 | 值 | 推导 / 代码 |
|---|---|---|
| 檐柱轴距（天宫） | `3.4m` | `nx = round(w / 3.4)`，`src/sky/palace.ts:687` |
| 柱身直径（天宫檐柱） | `0.48–0.50m`（r `0.24/0.25`） | `src/sky/palace.ts:700-702` |
| 天宫巨柱四级 | `4.80` / `3.40` / `2.30` / `1.50` | `src/sky/palace.ts:2266-2271` |
| 柱身净高 | `18.0m` | `src/sky/palace.ts:2202` |
| 柱础 / 柱头箍 | `0.7m` / `0.5m` | `src/sky/palace.ts:2203-2204` |
| 柱总高 | `19.2m`（`0.7 + 18.0 + 0.5`） | 同三行相加 |
| 柱列距（天宫大院） | `4.45m`，200 根 | `src/sky/palace.ts:2150` |

**柱径 : 柱高**（用 `19.2m` 柱总高除四级柱径）：

- 角墩 `4.80` → `1 : 4.0`
- 轴柱 `3.40` → `1 : 5.6`
- 间柱 `2.30` → `1 : 8.3`
- 余柱 `1.50` → `1 : 12.8`

这是**同一座建筑内部的四级差**，不是四套可选风格。判据：角柱必须最粗，余柱必须最细，任意两级的比值不得倒挂。

檐柱（人间）柱径 `0.5m`、净高由檐口反算：`hc = eaveY - 0.55 - yBase - 0.2`（`src/sky/palace.ts:686`），二层楼阁实测 `3.35m` → `1 : 6.7`。

### 3.3 开间 : 进深

- 街屋地块：面阔 `6–16m`、进深 `5–12m`（`src/city/buildings.ts:2706-2713`）。
- 单栋开间数：`1–3`，由 `round((w - 1.4) / 3.2)` 决定（`src/city/buildings.ts:1016`）。
- 地块中位约 `10 × 8`，比值 `1.25`。
- 规则：**进深不得大于面阔的 1.6 倍**。超了正脊会短于建筑长向，读成「侧着盖的棚」。机检 `probe-plot-ratio`（待建）。

### 3.4 檐口出挑 : 柱高

| 场景 | 出挑 | 与柱高之比 | 代码 |
|---|---|---|---|
| 街屋 | 墙外皮 `+0.6m` | `0.6 / 3.35 ≈ 1 : 5.6` | `src/city/buildings.ts:1308-1309` |
| 民居（远景实例） | `ROOF_EAVE_OUT = 0.6` | 同上 | `src/city/infill.ts:1178` |
| 天宫檐柱 | 柱心外 `0.36m` | `0.36 / 3.35 ≈ 1 : 9.3` | `src/sky/palace.ts:692` |
| 天宫屋面 | 每侧 `3.85% × 面阔` | 34m 殿 → `1.31m` | `src/sky/palace.ts:56`（`0.9231`） |

反算公式必须记住：`roofOn` 的**实际檐口 = 0.4615 × 入参面阔**（`0.5 × 0.905 × 1.02`，`src/city/buildings.ts:1306`）。所以想要「墙外皮 +0.6m」，入参要写 `(w / 2 + 0.6) / 0.4615`；直接传 `w + 0.5` 会变成「没有出檐、被墙头包住」。

### 3.5 台基高 : 殿身高

| 场景 | 台基 | 殿身 / 柱高 | 比值 | 代码 |
|---|---|---|---|---|
| 街屋 1 层 | `0.6m` | `3.2m` | `1 : 5.3` | `src/city/buildings.ts:879` / `:754` |
| 街屋 2 层 | `0.6m` | `6.4m` | `1 : 10.7` | 同上 |
| 三大殿 | `3 × 1.55 = 4.65m` | 檐口 `26m` − 台基 = `21.35m` | `1 : 4.6` | `src/city/imperial.ts:959` / `:222` |
| 天宫柱列院 | `9 × 1.55 = 13.95m` | `19.2m` | `1 : 1.38` | `src/sky/palace.ts:2199-2204` |

**天宫的台基不是「高一点」，是把台基当主立面做**：台基高与柱高接近 `1 : 1.4`，九层逐层收进。这是「巨大感来自比例而非绝对尺寸」的唯一量化出口（`src/sky/palace.ts:2145`）。

### 3.6 须弥座收分

九层台基每层相对台面的外扩：`[0, 0.30, 0.62, 0.95, 1.35, 2.20, 3.40, 4.60, 5.80]`（`src/sky/palace.ts:2261`），底层比顶层宽 `11.6m`。

判据只有一条：**自下而上单调收进**。写反了就会成倒锥——`src/sky/palace.ts:2259-2260` 记录了 B5 版写反（`halfW - 0.8*i`，上宽下窄）的事故。

### 3.7 瓦垄、斗栱、墙垛

| 项 | 值 | 说明 | 代码 |
|---|---|---|---|
| 瓦垄间距 | `0.34m` | 宋式 0.28–0.35 取中；224m 殿在 150m 外仍有 ≈2.4px | `src/city/bake.ts:239` |

### 3.8 天宫院落

- 每院台基底面 `145 × 115m`（`TG_COURT_HW 72.5` / `TG_COURT_HD 57.5`，`src/sky/palace.ts:2207-2208`）。
- 每院 `100` 根柱，两院合计 `200` 根（`src/sky/palace.ts:2206`）。
- 柱心退台面边缘 `3.0m`（`src/sky/palace.ts:2209`）。
- 宫台面 / 前庭面 `235.86m`（`src/sky/palace.ts:2198`）。

这四条决定了「院落」的读法：柱子退进台缘 3m，留出一圈可走人的边廊；台基 13.95m 高，人在台面上看柱只看到柱身下半段，因此柱头箍与斗栱必须在 `18m` 以上仍有足够厚度（柱头箍 `0.5m`），否则仰视时读成一根没有收头的白杆。

## 4 形制清单

每条给「正确样子」与「常见错误」。正确样子必须能在代码里指到实现；指向不到的标 `待建`。

### 4.1 屋顶

**庑殿（wudian）** — 五脊四坡，一条正脊 + 四条垂脊，**两端无山花**，正脊两端置鸱吻。
正确：`skyRoofOn(..., 'wudian', ...)`，两端坡面用 8 段贴面封闭（`src/sky/palace.ts:87-95`），正脊宽度以「单元平顶」为唯一依据，`RIDGE_F = 0.16`（`src/city/buildings.ts:277`）。
错误：正脊按 `sw × 0.39` 画 → 脊比屋面进深还长、两端悬空 2m 以上（`src/city/buildings.ts:272-274` 记录了这个事故）；±x 两端敞口，侧看能看进空腔。

**歇山（xieshan）** — 上部两坡 + 下部四坡，山花退进（收山），有博风板。
正确：`shouShan = min(1.2, w × 0.055)`（`src/sky/palace.ts:98`），垂脊从山花基角起，不从脊端起（`src/sky/palace.ts:110`）。
错误：山花不退进、与檐口齐平；垂脊从脊端一路拉到檐角，等于画成庑殿。

**悬山（gable）** — 两坡出挑，檩头外露，山墙不外露窗。
正确：`gableRoofOn(b, w + 0.3, d + 0.3, ...)`（`src/city/buildings.ts:1313`）；两山出挑 `0.34m`（`w ≥ 15`）或 `0.03m`（硬山，`src/city/infill.ts:1176`）。
错误：山墙开窗（§5-3 明令禁止）；出挑过大把山墙三角挡死。

**攒尖（zanjian）** — 四角 / 多角交于宝顶，**无正脊**。
正确：`skyRoofOn(..., 'zanjian', ...)`，`kH = 1.1`（最陡）；攒尖无正脊，`0.32 × 0.32` 平盖即宝顶座（`src/sky/palace.ts:122-125`）。
错误：攒尖顶上再加一条正脊；宝顶直接坐在瓦面上不设座。

### 4.2 斗栱

**正确**：位于柱头与额枋之上、檐口之下；攒距落在 `1.2–1.6m`；成圈连续，不中断；栌斗压在额枋外皮上（`src/sky/palace.ts:685`）。
**错误**：屋檐下没有斗栱（官式建筑直接扣盒子，`src/sky/palace.ts:677` 明确点名这是旧版病根）；斗栱只做正面、侧面断掉；攒距 <`1.2m` 挤成齿条，>`1.6m` 读成孤立托块。

### 4.3 栏杆

**正确**：望柱 + 栏板 + 寻杖三段式；坐凳栏杆凳面 `0.46m`、靠背寻杖 `0.94m`、短柱间距 `≈1.1m`（`src/sky/palace.ts:710-726`）；汉白玉栏板用 `0xbfb197`～`0xeee3c9` 两阶，不整片同色。
**错误**：只有扶手没有望柱；栏板高度超过 `1.2m`（挡住视线，与「凭栏观云海」的构图冲突）；用 `glow` 做栏板边缘。

### 4.4 窗

| 类型 | 正确样子 | 常见错误 |
|---|---|---|
| 隔扇 | 落地、六抹（六段横向分隔）、成双成对；`src/city/imperial.ts:964` 记「六抹隔扇 72 扇」 | 做成半截窗；抹数随意 |
| 槛窗 | 下设槛墙 `0.9m`（`src/city/buildings.ts:1699`），窗洞 `1.15 × 1.35m`、下沿 `1.15m`（`src/city/buildings.ts:866`） | 窗直接落地；窗宽超过开间 1/3 |
| 支摘窗 | 上段支起、下段可摘；世界口径 ≤`2.0m`（`src/sky/realm.ts:268-271`） | 整块暗板贴墙，被判成一樘超尺寸窗 |

**窗的硬指标是全局的**：天宫窗世界口径宽/高都 ≤`2.0m`，容差 `0.05`（`scripts/probe-heaven-windows.mjs:31-32`）。凌霄殿选区总放大 `2.2 × 2.7273 = 6.0`，所以预缩放必须 ≤`0.3333`；选区外 ≤`0.9091`（`src/sky/palace.ts:323-327`）。人间窗按真实尺寸建，不受此限，但**任何窗都不得贴成一块无框暗板**——探针按「同色 + 共享顶点」的连通分量识别一樘窗，一整块暗板即使压了棂条也算一樘（`src/sky/palace.ts:336`）。

### 4.5 台基（须弥座）

**正确**：圭角 → 下枋 → 束腰（可带壸门）→ 上枋 → 莲瓣，五段齐全；自下而上逐层收进；台面压檐石单成一阶亮色（`0xeee3c9`）。
**错误**：无收分的直筒台（读成水泥墩）；上宽下窄的倒锥（`src/sky/palace.ts:2259` 记录的事故）；整座台基一个色（700m 外就是白板，`src/sky/palace.ts:2213-2216`）。

### 4.6 门

**正确**：
- 门洞净宽 `1.6–2.4m`、净高 `2.2m`、门楣底 `2.8m`（`src/city/buildings.ts:863-865`）。
- 板门允许做到 `2.6 × 2.9m`，但必须明确它是门不是窗（`src/sky/palace.ts:783`）。
- 天宫门扇按 `3.0m` 建（`src/sky/palace.ts:2148`），因为天宫人尺度是 `1.7m`，门高须为人的 1.7–1.8 倍。
- 门洞两侧必须留墙垛 ≥`0.15m`（`src/city/buildings.ts:1049`）。

**错误**：门洞净高 <`2.0m`（视觉上要低头）；单扇门宽 >`2.6m`（推不动，且与开间模数打架）；门扇直接落地、无门槛石；门洞紧贴山墙角（无墙垛）。

## 5 禁止项（18 条）

每条给判据与检出方式。「机检」= 已有探针；「待建」= 需要新探针。

1. **窗户世界尺寸 > 2m**。判据：包围盒 `max(宽, 高) ≤ 2.0 + 0.05`。机检 `probe-heaven-windows`。
2. **屋檐下无斗栱**（官式建筑）。判据：檐口下 `0.3–1.2m` 带内无 `metal/wood` 斗栱簇。待建 `probe-dougong-presence`。
3. **山墙开窗**。判据：悬山 / 硬山建筑 ±x 山墙面存在窗色（`0x2a1a10` / `0x2a2118`，口径见 `scripts/probe-heaven-windows.mjs:33`）连通块。待建。
4. **白玉台无收分或收分倒挂**。判据：九层台基半宽序列必须单调递减。待建 `probe-podium-taper`。
5. **金色大面积平涂**。判据：`glow` 组单件面积 >`0.5m²`（`src/sky/palace.ts:17`），或单立面金饰覆盖率 >`35%`【规，沿用 `docs/assets/44-材质色彩总谱.md:49`】。待建 `probe-gold-area`。
6. **紫褐色天空**。判据：`H∈[270,330]` 且 `chroma < 22` 的像素占比 >`15%`。机检 `probe-atmos`。
7. **平白纸面云海**。判据：云海掩膜亮度标准差 <`12`。机检 `probe-cloudsea`。
8. **`glow` 用于结构件**。判据：`glow` 组构件的包围盒与柱 / 墙 / 台基 AABB 相交。待建。
9. **`wood` 用于石作**。判据：台基、栏板、须弥座构件的组名不是 `ash`。待建（可由 `probe-boxaudit` 扩展）。
10. **纯黑 `#000000`**。判据：任何顶点色线性亮度 = `0`。机检 `probe-glare` 的反向检查（待建 `probe-black`）。
11. **霓虹跨业态**。判据：品红 `0xff2e88` / 电紫 `0x8a2be2` 出现在民居（`house`）立面。已有结构约束（`src/city/buildings.ts:80`），待建探针。
12. **天宫出现霓虹**。判据：天宫区域（`y > 2131`，云海顶面标高见 `src/sky/heavenFrame.ts:16`）出现 NH 五色。待建。
13. **地府出现汉白玉**。判据：地府区域（`y < -100`）出现 `0xe0d3b6` 以上亮度的石作。待建。
14. **正脊悬空 / 脊长超过屋面进深**。判据：正脊端点必须在坡面上方 ≤`0.3m`。待建 `probe-ridge-seat`。
15. **屋面直线（无反宇）**。判据：屋面剖面偏离 `(1−t)^1.35` 超过 `0.05 × H`。待建。
16. **水面用 PBR**。判据：`water` 组材质类型不是 `MeshBasicMaterial`，或 `opacity ≠ 0.85`（`src/city/bake.ts:1485`）。
17. **同一建筑三阶金齐上**。判据：单栋建筑同时出现 `GOLD_ROOF`、`GOLD_TRIM`、`GOLD_LINE`。待建。
18. **彩画带出现在民居**。判据：`PAINT 0x2f5f5a` 出现在 `house` 类建筑。待建。

### 6.1 天宫母题（5 条）

§6.1–§6.2 的判据均为【规】：母题是构图规则，代码里没有对应常量，落地时由实现方补。

- **T1 缠龙浮雕柱**：柱径 ≥`1.5m` 才允许做浮雕（对应四级柱里的间柱以上），浮雕凸起 `5–20cm`，柱础与柱头箍单独包金。判定：柱身有独立几何起伏，不是贴图。
- **T2 龙首吐水 / 崖口跌水**：出水口在台缘外侧，水体离开台缘后**垂直落差 ≥`30m`**，落点消失在云海而非地面。判定：水体终点 y 高于云海顶面。
- **T3 弧形柱廊**：曲率半径恒定、柱距等距、外侧栏板连续。判定：相邻柱心的曲率偏差 ≤`5%`。
- **T4 镜面地**：抛光深色石 + 倒影。代码对应台面外圈 `0x6b6152`（线性 `0.123`，`src/sky/palace.ts:2236`），**不是** `water` 组。
- **T5 三重门楼**：门洞高宽比 ≈`2:1`，两侧石狮，门前镜面水道。判定：门洞净高 / 净宽 ∈ `[1.8, 2.2]`。

另有 **T6 悬空编钟**（R06）：大件悬吊、水面同心圆扩散；判定：钟体下沿与水面的距离 ≥`2m`，水面有 ≥3 圈同心环。

### 6.2 通用母题（3 条）

- **G1 巨构比例尺**：以 `1.7m` 的人为尺（`src/sky/palace.ts:2147`），门洞净高 ≈`8–12` 人高。任何「巨大感」必须有人作参照；没有参照的巨构在截图里读不出尺度。
- **G2 云海硬边 / 柔边对比**：台缘是直线硬边，云顶是柔边，两者交界不得互溶。判定：台缘边缘梯度 ≥ 云顶边缘梯度的 3 倍。
- **G3 单光源逆光 + 边缘光**：主光在画面后方，构件边缘出亮线，正面压暗。

### 6.3 参考图不可照抄的部分

这 16 张是生成图，**形制层不可信**，只可取母题：

- R02 出现哥特尖拱与卷草，非中式；只能取「全白玉 + 金线 + 镜面地」三件事。
- R10 是金属圆环，完全非中式形制，**禁抄**，只可借「以人为尺」的构图。
- R14 的悬挑环状结构在力学上不成立，**禁抄结构**，只可借「柱廊沿曲率延伸」的组织方式。
- 多数图的斗栱被简化成托块、柱头无卷杀、屋面无反宇曲线——这些正是 §4 要纠正的部分。**参考图与 §4 冲突时，以 §4 为准。**
