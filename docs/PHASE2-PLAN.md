## 排期与批次建议（小步快跑，单步 15-30min 窄步闸）

- **批次一（P0 叙事闭环）**：M1 → M2 → M3。理由：十八狱是地府主干体验的最大空洞（现为环形占位）；内饰让「走-看-交互」在重点建筑闭环。
- **批次二（P1 密度填充）**：M4 ∥ M5（可并行，无共享文件）→ M6。
- **批次三（P1/P2 深化）**：M8 ∥ M7 打样 → M7 批量 → M9（等资产到位）。

## 每里程碑验收模板

1. 功能：新增场景/内饰/物品在 `__qingming` 就绪后可到达、可交互（e2e 新增断言：POI 传送不穿模 + 交互点可用）。
2. 性能：draw calls 增幅 ≤ +8（复用烘焙/实例池管线）；audit 全机位 ≥ 50fps（本机基准）。
3. 一致性：坐标过总纲 §四红线（中轴 ±26m / 高程带 / 入口唯一 / 三币单向兑换）；ID 顺延不重号。
4. 证据：截图入 `screenshots/`，PROBLEM-SPEC 增补行记录。
