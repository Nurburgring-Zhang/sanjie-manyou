# 《赛博上河 · NEON BIANJING》项目描述 v1.0

> Three.js 沉浸式赛博国潮 3D 漫游场景：全 3D 复刻《清明上河图》整城 + 水浒 108 将 + 天空层《大闹天宫》。纯前端实时渲染，零外部美术资产（100% 程序化生成），可离线运行，双端交付。

## 1. 全局架构

| 项 | 决策 |
| --- | --- |
| 技术栈 | Vite 7 + TypeScript(strict) + Three.js(r180) + WebAudio；Electron Windows 壳 |
| 后端 | 无（纯静态前端，零网络依赖，可完全离线） |
| 资产 | 零模型/贴图/音频文件；建筑、人物、动物、道具、纹理（canvas 汉字招牌）、音效全部程序化生成 |
| 随机 | mulberry32 确定性种子，同种子同城市（可复现、可测试） |
| 渲染 | WebGL2，EffectComposer（Bloom + 青绿调色 Grade + 暗角），昼夜循环光照系统 |

## 2. 世界布局（长卷方向 X 轴 ≈ 1200m × Z ≈ 500m，六大地面区 + 天空层）

- **A 郊野区** (x -600~-350)：田垄、柳林、农舍、驴队、扫墓返城队伍（开卷段复刻）
- **B 汴河漕运区** (x -350~-100)：汴河（宽约 60m 横贯）、码头、漕船货栈、纤夫道、柳岸
- **C 虹桥核心区** (x -100~+100)：**木质拱虹桥（标志性复刻）**、桥头酒肆摊贩、**大船降桅过桥戏剧（循环上演）**
- **D 街市区** (x +100~+400)：十字街、孙羊正店/十千脚店（彩楼欢门）、茶坊、绸缎庄、香药铺、赵太丞医铺、解当铺、说书瓦子勾栏、骆驼商队
- **E 城门区** (x +400~+550)：城楼城墙门洞（驼队穿行）、税务所
- **F 城内延伸区** (x +550~+600 + Z 纵深)：衙署、府邸、民居巷弄、佛塔、道观
- **G 天空层** (y 180~400)：云海平台群、南天门、凌霄宝殿、蟠桃园、云桥、银河星带——大闹天宫战场与神佛日常独立运转

## 6. 美术基调（主人已确认：暮色霓虹 + 昼夜循环）

- 宋韵底：石绿 #2E8B6D / 石青 #3A6B8C / 绢底暖褐 / 朱红柱 / 灰瓦
- 赛博光：霓虹青 #00E5FF / 品红 #FF2D95 / 鎏金 #FFB300
- 昼夜：黄昏（默认）→ 夜 → 黎明 循环，可暂停/手动切档；天色/雾/灯强/霓虹亮度全联动

## 7. UI/UX

水墨加载屏（进度+分帧生成）→ 可跳过电影运镜开场 → 底部功能栏（视角切换/昼夜/人流密度/画质/音效/图鉴/帮助）、图鉴面板（水浒108/西游神佛/市井百业 三页签，点击飞至）、右上 FPS 与在场人数、战报 ticker、点击角色信息卡、小地图（POI+主角实时点）、设置面板、移动端虚拟摇杆+双指缩放+按钮化操作、首访操作引导。

## 8. 音频（WebAudio 全合成，零音频文件）

## 9. 性能预算与分档

- 目标：桌面中端 GPU 60fps / 移动旗舰 30fps；draw call < 900、高档三角形 < 3.5M
- 三档画质：高档（全密度 ~850NPC+阴影 2048+全 Bloom）/ 中档（60% 人群+半分辨率 Bloom）/ 低档（30%+无 Bloom+无阴影）；FPS 滚动采样**自动降档**
- 建筑合并几何 + 远景 LOD 简化；世界生成分帧执行 + 进度显示

## 10. 测试与验收

- vitest 单测：种子确定性 / 布局不变量（路网连通 BFS / 建筑在地块内）/ 108 将数据完整性（108 人、36+72、名号唯一）/ 行为状态机转移 / 天宫编排时间轴合法性
- 真实运行冒烟：开发与生产构建浏览器加载，控制台零报错，关键 POI（虹桥/街市/天宫战场）截图核验，FPS 实测采样，UI 交互点击链路
- 上线测试 ≥2 轮（dev 与 vite preview 双链路）；Electron 壳真实启动验证

## 11. 双端交付（主人已确认）

- Web：`npm run build` → dist/ 静态站点（桌面+移动浏览器自适应）
- Windows：electron/ 壳加载本地 dist → electron-builder 打包 portable exe；若打包器二进制下载受阻，则交付「本地启动器脚本 + 完整打包配置」并如实标注

## 12. 边界（明确不做）

不做多人联机/后端账号；不做历史人物肖像级还原（风格化）；涉黄涉赌以宋代风俗呈现（青楼=乐坊歌舞、赌=骰牌游戏，无露骨内容）；不承诺逐笔复刻原画构图，承诺六大区段 + 虹桥降桅/城门驼队/正店彩楼等标志性场景逐一 3D 复刻。

## 13. 里程碑（每步 15~30min，小步快跑）
