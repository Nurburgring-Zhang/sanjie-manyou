## 二、统一角色卡模板（12+ 字段，一员一卡）

形貌（含肤色 hex/身高/独特记忆点）→ **原著身长体型（原文尺度+换算+游戏归一）→ 原著容貌/图像志引文（标回目或像设出处）→ 行为习惯（原著性格外化 2-3 条）** → 须发 → 头衣 → 服装（逐件：形制/主色 hex/缘边/纹样题材/材质质感/磨损）→ 甲胄 → 束带配饰 → 鞋袜 → 面身标记（刺青/黥文/鬼纹）→ 兵器法器（逐件）→ 动作签名 → 声音语气 → 灵气/鬼气表征 → 驻留位与日常（引资产卷区域 ID）。

## 三、硬约束

1. **独一无二**：记忆点、动作签名全库不得重复（已程序化查重）。
2. **代码锚定**：实装角色的姓名/武器/坐标/行为以 `src/data/` 花名册为准，1:1 覆盖（天宫 35/35、人间 108/108、地府 66 个体）。
3. **原著符合性**：形象与《水浒传》/《西游记》/佛教像设/道教科仪/民俗定式冲突时以原著为准修正并注 `〔依原著修正〕`；代码原值保留备注。
3. **服化道完备**：服装逐件到"材质质感+磨损度"，法器到"尺寸+光色+收纳方式"。
4. **色彩可执行**：全部色彩给 hex（三卷合计 2,920 处 hex 标注），材质词汇对齐 44 卷材质库（M-01..25）。
5. **个体参数化**：群体角色（恶鬼 34/游魂 22 等）给出"肤色池×衣色池×破损度×体型"参数表，保证同模板个体不重样。
