**卷首·编纂口径**

- 本卷为 `10-天宫资产全录.md` 的角色姊妹卷：区域/建筑/物品/仙兽 ID（T-ZZ / T-GZ / T-ITM / T-CRT）沿用 10 卷不另造；本卷新增角色 ID 段 `CH-T-NNN`。
- ID 规则：CH = Character（角色），T = 天宫序列，NNN 为三位流水号 `CH-T-001 ~ CH-T-077`，全局唯一、不复用、不跳号。
- 每员 15 字段：形貌 / 身量与体格 / 图像志依据 / 行为习惯（性格外化） / 须发 / 头衣 / 服装 / 束带配饰 / 鞋袜 / 面饰妆容 / 兵器法器 / 动作签名 / 声音语气 / 灵气表征 / 驻留位与日常；「身量与体格」「图像志依据」「行为习惯（性格外化）」为 v1.1 图像志符合性修订新增（插于形貌之后，考据源与统计见卷末修订记录）；「unique 记忆点」为形貌末句，「动作签名」独立成段，两者全库唯一、互不重复。
- 色彩一律给 hex；材质一律附质感（反光度 / 垂坠感 / 磨损度）。代码已实装角色（`src/data/deities.ts`，35 员）的服色以代码 cloth / pants 值 1:1 嵌入外袍与下裳主色。
- 代码 hat 字段映射：0=不戴冠（巾栉 / 裸髻），1=冠冕（帝王官将），2=兽形额饰 / 战盔，3=仙髻花饰（女仙 / 僧羽流）。
- 诚实注记：本卷共 77 员，其中 35 员为代码花名册角色（覆盖率 100%），42 员为花名册外补充角色，逐条标注【补充】，来源为 10 卷驻留 NPC、十幕大战参战者与职司补全，未虚构代码中不存在的实装事实。三清之中元始、灵宝二尊于 T-ITM-0164「三清讲经席」留位但未出场，本卷不立传；地藏菩萨属幽冥序列（见 30 卷 T-ITM 地藏龛），不跨卷立传。
