## 三、本轮已落地（沙箱内可完成的部分）

1. **派生 PBR**：从现有 albedo 程序化导出 AO 贴图（32px 盒式亮度遮蔽）与粗糙度区间，屋顶/地面升级 `MeshStandardMaterial`（roughness 0.92/0.96）——真实派生数据，非占位。
2. **法线补全**：屋顶瓦垄法线接入材质（1.1 强度）+ 新增地面夯土法线。
3. **软阴影**：PCFSoftShadowMap 已启用（shadow.radius=4），地形接收建筑投影。
4. **纹理精度**：主纹理 512px + anisotropy 8 + 瓦面 AO/苔痕/瓦当滴水/车辙碎石细节层。

## 四、二期引入执行手册（需有外网访问的打包机）

```bash
# 1. 拉取（幂等，直链即可）
curl -L -o temp.zip "https://ambientcg.com/get?file=RoofingTiles013A_1K-JPG.zip"
# 2. 解包后拷入 public/tex/{roof,ground,wood}/{alb,nrm,rgh}.jpg
# 3. 代码接入点：src/city/bake.ts build() 材质表——
#    roof/ground/wood 换 THREE.TextureLoader().load('tex/...') 三件套，
#    colorSpace: albedo=SRGBColorSpace, normal/rgh 保持 Linear；
#    vertexColors 保留（逐建筑色相乘混色）。
# 4. 角色 glTF 化（Quaternius RPG 角色包 → GLTFLoader + 换装色）：
#    替换 actors/pools.ts 胶囊人为 SkinnedMesh 实例化（需二期重排 actor 管线）。
# 5. HDRI IBL（Poly Haven klokantifaust/dusk 案）→ PMREMGenerator 环境贴图，
#    scene.environment 接入后可关 RoomEnvironment。
```
