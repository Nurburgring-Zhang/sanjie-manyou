### 2.1 忘川河（黄泉河）水性

| 属性 | 设定 |
| --- | --- |
| 水色水质 | 暗红（#4a0d12），河面 y=-262，主航道深至 -276；水面终年浮红雾，雾贴水面 0.8m 厚 |
| 低语声 | 贴近水面 5m 内可闻密语声浪，细听是无数亡者姓名被反复念出；玩家靠近时低语中会混入玩家角色名，作惊悚提示 |
| 水性规则 | 阳人（玩家）触水即触发「记忆剥落」：已探索迷雾回退一格、屏幕边缘泛红 10 秒；恶鬼入水则沉底化入水鬼 |
| 渡船规则 | 只允许挂"火印籍"（已过鬼门关验籍）者乘渡；渡资为阳间纸钱灰一撮（投入渡资灰钱匣）；航线固定 归魂渡→迎魂渡 偏东侧水道，航时 90 秒，绕开桥下水鬼三点位 |
| 渡船禁忌 | 船上不得呼名点名——点名者脚下水纹成其名，水鬼循名而至（演出 + 水鬼刷新） |
| 汛期 | 血月满相之夜为"忘川汛"，水面抬升 0.6m，锁魂链浮出水面，游火密度翻倍 |
