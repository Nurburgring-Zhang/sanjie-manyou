## ② V 系设计要点（V13/V14/V15）

**V13 六道阶位**：阶位是**权限阶梯**不是难度阶梯，可回走；核心原则「换阶必须换玩法动词，不能只换数值」（地狱 受·记·翻 / 饿鬼 饥·吞·舍 / 畜生 嗅·循·驱 / 人 交易·结交·造物 / 修罗 誓·斗·夺 / 天 巡·裁·赐）。六阶空间锚点全走代码真值（POIS/shibayu、fengdu、countryside、heavenPoint 落点）。业力系统：数据结构、累积表（每条可接线）、可堕落可超脱、**业力没有经济口**（与三币隔离）。跨阶保留与损失规则；六阶与 V14 的数据契约；**最小改造七步**（不是六套碰撞，是连一套都没有——先纠前提）；明确不引入 Spore 太空/部落 RTS/文明建造/细胞微观/自由蒙皮五件事。
**V14 造物编辑器**：八槽十实例（8 槽指类型；躯干唯一必填决定体量系数 K）；挂点拼装三硬理由（无蒙皮/面数可预算/确定性）；9 型原型=选骨架；96 件部件库全部由 VGeo 图元拼成；三类拼装规则（互斥/依赖/缩放）+ 校验器 + 蓝图哈希；属性派生五公式落到既有系统；**程序化软体蒙皮 → 预烘焙拼装**（Spore 自由度是护城河也是移动端毒药，不追）；四类用途（坐骑/宠物/机关/守卫）+ 成本总表；与 creatures/deities 共存不造第二轮子（24+42+35 同屏测试）。
**V15 业缘网**：三句话结论——业缘是「谁看见了什么、谁告诉了谁」的可追溯图；**没有观察者就没有边**；具名节点约 300 个（165 好汉+35 神佛+61+1 掌柜），4,500 路人无稳定身份不进图，态度聚合成坊/行会/场所。节点四类（person/faction/place/event ≤5,000 环形缓冲）、边 10 类（恩/仇/债/亲缘/香火…各带半衰期）、按游戏日衰减、SoA+CSR 存储、行为→业缘映射 36 条、流言传播失真反号、自动编年史（确定性模板不调模型）、规模上限硬编码（堆 ≤8MB 实际 ~3.6MB、载入 ≤0.01s、~24 人日）。

## ④ 冲突裁决

1. **D4「ADR-5：不允许 Agent 生成 TS/JS，部件是预烘焙 id+参数」vs 修订版 ADR-5 + H3 实证。** 判给 **H3（勘误层第 4 条，凌驾卷内）**：代码构建路线成立不降级；D4 该句随 2026-11-03 ADR-5 修订作废。裁决后两条路线并存分工：**玩家手动编辑器**走 D4/V14 挂点拼装（产出 spec，参数档），**许愿 Agent**走 D5 五段管线（产出 build.ts→bundle，代码档）；两者产物同一 `bundle` schema，下游一行不改。
2. **V13 六道阈值 480 反推自不存在的 36 件内容 vs P1-5。** 判给 **清单 v3 P1-5**：先落业力来源表 + 每阶 1 个可重复动词 + 1 个产出，阈值数字随内容量重定；V13 的阈值 480 作废为占位。
3. **V15 节点数 300 vs V13/V8 的神佛计数 35 vs 60。** 判给 **实测 35**（`DEITIES.length`，D6 §0.2.1 可证伪表原判；V15 §1.1 表已用 35，V13 若出现「约 60」以 35 为准）。
4. **V15 业缘存档 vs 三键 localStorage 现状。** 判给 **P0-4 吸收**：业缘图作为 SaveV4 的一节进 IndexedDB（H4 GO），V15 的「自带版本化存档」不再自建，统一走 save.ts 的 schemaVersion/migrate。
5. **V15 事件环形缓冲 ≤5,000 vs V13 业力 0–9999 计数。** 三方一致无冲突：业力是**累计标量**（S06/S10 共享单点真相），业缘是**图**（事件节点缓冲）；两套载体不同，字段不合并。
6. **形状门缺口。** 判给 **勘误层**：P2-3 必新增形状门（多视角截图 + 长宽比/连通域启发）；四门 PASS 不得再宣称「造物验收完成」。
7. **`LegSpec.n` 不被读取。** 判**记录不改**（D4 原话「不是本卷要修的」）：列为依赖项，凡按 n 算腿数/面数的预算一律以 z 口径重算；修复时机挂 P2-1（构建 API 实现时顺带）。
