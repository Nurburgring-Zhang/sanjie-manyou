# S11 · 游戏内 Agent 与双 AI 议会（融合终版）

> 素材：D5《游戏内 Agent》× D6《双 AI 议会》× H3 沙箱实证（无 V 系对应卷）。

## ① 代码现状（实测锚）

**游戏内 Agent 零实现**：`src/` 无许愿入口、无意图解析、无沙箱执行器、无议会模块。已存在的只有**离线验证件**：`creations/dragon/build.mjs`（手写程序化生成器，纯常量驱动零随机）→ `creations/dragon/dragon.json`（1,141 tri / 22,596B / seed=20261104 双跑逐字节 IDENTICAL）；`probe-creation-bundle.mjs`（校验器，`--file` 与 `--self-test` 8 正 2 负全过，判据会红会绿）。H3 结论：**「agent coding 造物」路线实测可行，不降级为部件拼装**；手写 1,141 面 ≈ D4 九型实测 952 面的 1.2 倍，1,400 硬门禁对手写程序化造物预算合理；蛇形放样+挂点件手写 ≈180 行/3 小时当量。沙箱侧既有实证（D5 §2.2/§2.5）：`--experimental-permission` **拦不住 http/net/fetch**；`--max-old-space-size=32` **管不住 typed array**（320MB 照跑）——OS 级隔离是硬前置。构建 API 白名单现状：`box/cyl/sphere/roofC` 四个已有（`creatures.ts:185-428` VGeo 图元族），`lathe/extrude/tube/isosurface` 四个零命中。Electron 侧：IPC=0、CSP=0（清单 v3 P0-8 现状，`electron/main.cjs` 无 preload/白名单）。

## ② D 系设计要点（D5 卷）

范式改正：旧死结不是「部件不够」而是「代码在哪里跑」；表达力交给代码，安全性交给进程边界与四道门。**三件套**（可分别校验的单向流）：`CreationSpec`（意图与索引，纯数据，进存档与议会）→ `build.ts`（过程，只调白名单 API，不 import 任何东西，只在沙箱执行）→ `CreationBundle`（产物，几何缓冲+四声明+预算+hash，纯数据进游戏进程；bundle 必带 spec，spec 不带 build.ts——代码不进存档，否则等于把禁令从后门放回来）。五段管线预算表：P1 意图解析 200ms/200ms（低置信 <0.55 强制澄清、消歧顺序量词>场景>会话偏好、黑名单早拒绝）；P2 生成 150ms 模板/120s 模型两种实现一个出口（tier=reuse/param/code 三档在 P1 定，决定要不要付 64ms 沙箱启动费）；P3 沙箱 60s 体验预算/180s ADR-5 硬超时（两数不重复：前者管体验后者管安全）；P4 四道门 50ms（面数/包围盒/内存/不确定性，减面重试一次）；P5 热替换 300ms（hash/落点/帧超 1.1× 拒收，失败原子回滚）。三等分：L1 复用 ≤300ms / L2 参数化 ≤3s / L3 代码生成 30s~3min。四条永久边界：新材质组（破 14 组合批）、新机制（behavior 只五值）、联网、超预算（>20,000 面/>200m/>8MB 硬拒）。表达力账：盘绕 tube/鳞片 extrude/云雾 isosurface，盘龙 8,212 面占预算 41%。三层 hash 各管一件事；回滚把不可逆一步放最后；失败话术六条统一三段式。

## ③ D 系设计要点（D6 卷）

两种议会切开：**设计期议会**（离线，产物 ADR/卷册/勘误清单，裁判=人+机检，已验证有效——第一轮 1 放行 15 打回、第二轮 8 条打回 + 1 条编造，七条样本全部可证伪：V10 127 处复现不出、V11 33 flush 实为 36、V13 行号漂 12 处、V14 灵狐 810≠750、V15 神佛 60 实 35、V16 量纲错 60 倍）与**运行期议会**（玩家许愿时在线，产物 build.ts+spec，失败代价=玩家等几分钟）。运行期四步：A 起草（IntentFrame→spec+build.ts 整份重写不做 patch）→ B 攻击（只读两件，只输出五类封闭枚举：不可实现/超预算/违和/违反物理/违反阶位）→ 裁判 C 跑 C1–C6（**裁判不是模型**——两个模型对喷会互相让步一起错，校验器只会返回 E_GATE_TRIS）→ 出门交 D5 P4/P5。**只有 L3 代码档开会**（L1/L2 不开：把 200ms 的事拖成 3 分钟是把自己放回错误位置）。硬上限：≤3 轮、≤12,000 token、≤5min；收敛判据六条全可机检；僵局三级；议会不能打断玩家；「议会也救不了」的五类硬边界 + 把「不行」变成一条路（拒绝之后给可达的替代）。

**D5/D6 细节补充**：D5 §2 沙箱三候选按「隔离强度/启动成本/可观测性」三轴对比，A 方案（Node 子进程）实测三件事——权限模型拦不住 net、内存旗标管不住 typed array、启动约 64ms；B 方案强在断网、弱在回收；C 方案快但「不是边界」。选型结论=A 为骨架 + OS 级隔离补刀。D5 §3 表达力账单：tube 分段与锥度表达盘绕、extrude 密度控制表达鳞片、isosurface 是唯一能表达「无定形」（云雾）的方法；盘龙 8,212 面占 20,000 预算 41%；§3.7 自认三个表达力缺口。§4 bundle schema=ADR-8 逐字 + 四个信封字段；三层 hash 各管一件事（内容/预算/溯源）；回滚把不可逆一步放最后；失败话术六条统一三段式（发生了什么/为什么/下一步能做什么）。§5 热替换五动作精确含义、时序与唯一的危险窗口、100m 落点三条硬规则、**天宫陷阱：268 不是世界坐标**（落点表里出现 pre-lift 口径值必须换算，呼应 S02 口径陷阱族）。D6 §3：三轮硬上限、收敛判据六条全可机检、僵局三级处置、成本上限 12,000 token / 5 分钟、议会不能打断玩家（异步通知 + 完成后挂载）、禁止事项清单；§4「议会也救不了」五类硬边界 + 拒绝话术三条纪律 + 三种最糟的回答（含「假装能做到」）+ 拒绝之后把「不行」变成一条路。

**D5 §1.2/§1.3 补充**：意图解析的失败处置三档——低置信（`confidence < 0.55`）不猜、进三选一澄清（每个候选带 96×96 预览与一行代价，如「盘龙柱 · 约 3.5k 面 · 20 秒」）；多义消歧顺序「量词 > 场景 > 会话偏好」不可反（量词是刚打的字意图最明确）；越界词命中黑名单直接 `refuse` 不进后续段（早拒绝省一次 64ms 启动加一次 3,000 面构建）。超时（>200ms）降级：用最近一次成功 `IntentFrame` 填默认值并把 `confidence` 压到 0.5 以下强制澄清——宁可多问一句，不可猜错一次（猜错的代价是 60s 沙箱执行 + 一次回滚）。P2 双实现对照：模板（150ms，确定性词表驱动）与模型（120s，`build.ts` 全文生成）产物形状完全一致 `{code, spec, moduleHash}`——模型写坏时模板顶上，模板表达不了时模型来写，二者产同一 bundle schema，下游一行不改。

## ④ 冲突裁决

1. **D4 旧 ADR-5（数据不是代码）vs D5 新范式 + H3。** 判给 **D5/H3**（同 S10 裁决 1）：D4 卷该句作废；本系统是代码构建路线的执行主体，D4/V14 拼装编辑器降为参数档（L2）与玩家手动 UI。
2. **D5「stdout 一行 JSON」vs D7「只走 bin」互斥。** 判给 **D7/清单 v3**：P2-3 二进制传输定案，且顺序上 P2-3 先于 P2-2（先跑通 JSON 通道等于先建一条已知要拆的层）；D5 §1.3 的 stdout JSON 描述标记为 v1 演进史。
3. **D5 沙箱 A 方案（Node 子进程+权限模型）vs §2.2 实测拦不住 net。** 判给**实测**：`--experimental-permission` 不作为安全边界，只作纵深防御之一；强制项=OS 级隔离（Job Object/防火墙/无网容器）+ 180s 硬超时 + 内存上限（含 typed array 的外部护栏，如 ulimit/容器配额）。
4. **议会三等分 vs 现状零实现。** 无分歧：L1/L2 不开会、L3 ≤3 轮进 P2-5；设计期议会机制已被本项目工作流实偿验证（本融合文件本身即其产物），不进游戏内排期。
5. **H3 遗留：positions 无 normals/colors、单材质组鳞眼分色。** 判给 **P2-1/P2-3 顺带**：P2-1 定义必填性（normals 必填、colors 可选），P2-3 传输格式支持多材质组；不单开任务。
6. **构建 API 白名单 4 有 4 无。** 无分歧：P2-1 补 `lathe/extrude/tube/isosurface`，验收即清单原判据（生成一条龙 ≤20,000 面）。
