# S09 · 战斗与装备（融合终版）

> 素材：V9《战斗与装备》× 代码实测（boss.ts 两阶段状态机 / physics ImpactSystem 力分级）。

## ① 代码现状（实测锚）

**力分级 ≠ 伤害。** `src/game/physics.ts` 冲击分级（V9 实读 `:10-15`：F<0.8T 无效 / <1.6T 踉跄 / <3.2T 击倒 / <6T 击飞 / ≥6T 碎裂）；`ImpactSystem` 类：`FIXED_DT=1/120`、`MAX_SUBSTEPS=16`（`physics.ts:61-63`）、`launches = new Map<Actor, LaunchState>`（`:67`）、`apply(tier,…)`（`:101`）、`impactUntil` 按 tier 写 3600/1200/3500/4000ms（`:104-127`）；固定步循环 `while (this.acc >= FIXED_DT && steps < MAX_SUBSTEPS)`（`:254-255`）。玩家出手 `playerAttack`（`physics.ts:144`）：面前 2.4m、前向点积 ≥0.35 最近目标的单点球形判定——无扫掠无帧窗口。**Boss 现状是两阶段不是三阶段**：`phase: 1 | 2 = 1`（`src/game/boss.ts:34`）；状态机 `idle→engage→telegraph→active→dead/respawning`（`boss.ts:19`）；出招 `rollMove()`（`boss.ts:101`，随机源已注入 `:53-54`，默认 `DEFAULT_RNG` = core/rng mulberry32）；阶段闸门 `canGrab = phase === 2`（`:93-94`），阶段 1 绝不放擒拿（`:196` 显式守卫）；脱战回血 4%/s（`:166`）；阶段跃迁即换（`:120`）。数值 `src/data/boss.ts:38-44`：maxHp 320、hitDamage 按阶段取 `hitDamage[this.phase-1]`、meleeRange 12（判的是「玩家到 Boss 中心水平距离」——V9 指出 4.1m 体型的 Boss 11m 外空挥也命中）、sweep 0.9s 前摇/0.35s 判定/26m/140°、grab 1.2s/0.4s/13m。**玩家无 HP**（只有 `busyUntil` 与 `actor.impactUntil`）；装备只有一个乘数 `playerWeapon = {key:'fist',label:'双拳',mult:1}`（`physics.ts:71` 附近，钢刀 mult=2.5、炮 20）。大闹天宫 `src/sky/havoc.ts` 是自动演出（玩家输入改不了状态）。**无骨骼无动画事件**：`src/actors/actions.ts` 全部是 `t` 秒驱动程序化姿态，判定帧不能从动作里读。

## ② V 系设计要点（V9 卷）

三处纠漂移：巨灵神实际 4.1m 不是 9m（scale 2.35×基准 1.76m；真 9m 会撞天宫门洞与 camDist 上限 16m）；meleeRange 12 不是兵器长度（拆 `bodyRadius 2.2 + weaponReach 1.4 = 3.6m`）；回血以代码 4%/s 为准。**战斗基础**：60Hz 固定逻辑帧（SIM_DT=1/60、MAX_CATCHUP=4 防死亡螺旋、acc 累加器 + alpha 插值；代价=1 帧输入延迟或 0.5 帧视觉滞后二选一）；近战改**胶囊扫掠**（兵器线段 grip→tip vs 目标胶囊，每 active 帧 3 子步插值，`segSegDist2` 纯四则运算禁 `Math.hypot` 跨引擎差异）；命中盒 Hurtbox；无敌帧与闪避；受击硬直与削韧 Poise；击退；输入缓冲与取消窗口；一次命中完整时序算例。**与 ImpactSystem 接线**：CombatSystem 发 `combat:hit` 事件，ImpactSystem 只对 NPC 走力分级，玩家与 Boss 受击由 `stunTicks`/`BossBrain` 管——避免「一次命中既扣 HP 又被 launch 抛一次」双重结算；`playerAttack` 保留为徒手攻击内部转调。武器表 34 种（`WeaponSpec`：轻/重击伤害、rate、起手/判定/收招 60Hz 帧三元组、range、耐久、来源、tags）；护甲四槽 + 三套改造体系（符箓/淬炼/铭刻）与三个 Build 取舍；**Boss 扩七场**：`BossSpec` 扩成表驱动（现 2 招 → `BossMove[]`，阶段 3 + 弱点），与 `havoc.ts` 共存（共用演员与锚点，不把演出改成 Boss）；失败重开代价；人间通缉度把市井械斗变成可执行规则。性能：新 Boss 不得新增独立高模，复用 `DEITIES` 角色池 + Vfx 实例。

## ③ D 系设计要点（D 系无战斗卷，关联约束）

D7/D10 侧约束三条：**判定类输入固定步采样 + 100ms 缓冲**（P3-4；D10 算过 Boss 冷却期点击被静默丢弃 17.9%——冷却尾部点击不丢是验收）；D7 预算：Boss 战期间 Δ 面/Δ draw 走 ADR-7 账，复用池不新增 program；D9 HUD：Boss 血条/连击/耐久占用进 P1-8 布局矩阵。D4 造物参战（P1-6）的战斗属性入口必须走本系统的伤害管线，不自算。

**V9 细节补充**：§1.3-1.8 命中盒（Hurtbox 胶囊参数表）、无敌帧与闪避（i-frame 窗口与取消窗口）、受击硬直（Hitstun）与削韧（Poise 值决定硬直档位）、击退（与 ImpactSystem 力分级对表）、输入缓冲与取消窗口、§1.8「铁剑轻击→天兵」一次命中的完整时序算例（帧级拆解）。§2 武器表 34 种分八类（sword/dao/spear/staff/bow/crossbow/hidden/ritual），带成长曲线与经济锚、武器类→动作名映射（复用 `actions.ts` 既有程序化姿态名，不新增动画系统）。§3 护甲四槽与总护甲减法公式；三套改造体系（符箓/淬炼/铭刻）各自的材料来源、失败率与存档字段；§3.3 三个 Build 取舍展示差异化而非数值堆叠。§4 Boss 七场：`BossSpec` 扩表驱动（`BossMove[]`：帧三元组/判定/位移/削韧），与 `havoc.ts` 的共存规则（Boss 战借演员与锚点，演出状态机不被玩家输入污染——现状 `hold=true` 整场停摆的语义保留给演出侧）；失败、重开与代价（重开不重置探索进度）。§5 三界战斗差异与人间通缉度（把「市井械斗」变成可执行规则）。§7 落点与实现顺序、§8 十条验收断言、§9 未决与待验证。

## ④ 冲突裁决

1. **V9 固定步 60Hz vs `ImpactSystem` 固定步 1/120 并存。** 判给**双层固定步**：渲染/sim 主循环接 60Hz（P0-5 `src/rt/loop.ts`），ImpactSystem 保留 1/120 子步（弹道积分精度，现状已在用且与主循环不同轴不冲突）；接线方式=主步内累计 acc 喂 ImpactSystem，两套 FIXED_DT 语义在代码注释中显式区分（带限定词：sim 帧/物理子步）。
2. **V9 「Boss 三阶段/七场」vs 现状两阶段一场。** 判给**现状为基线、V9 为目标**：任务书口径「三阶段」与代码 `phase: 1|2` 不符，以代码为准记「两阶段」；阶段 3 与七场 Boss 是 P1-6 的内容扩展，`BossSpec` 表驱动改造先行（数据结构不返工）。
3. **V9 胶囊扫掠 vs H2 网格哈希碰撞索引。** 三方一致分工：H2 网格哈希管**空间邻域查询**（broadphase），V9 扫掠管**命中精判**（narrowphase）；扫掠只在 active 帧对邻域内少数目标跑，不进 4,400 点查/帧的热路径。
4. **V9 玩家 hp 0–100 样例（V10 SaveV4）vs V6 四维千分位。** 判给 **V6 千分位**（同 S06 裁决 1），SaveV4 字段域按 0–1000 收敛。
5. **V9 通缉度 vs 现状零实现。** 无分歧：通缉度进 P1-6（与 S06 死亡掉钱、S08 交互、S10 业缘目击共享事件总线），先落数据字段与两个触发（斗殴/袭警），文案级扩散归 S10 业缘网。
6. **V9 「禁 Math.hypot 判定」vs 现状 `Math.hypot` 出现在 `player.ts:250` 城区判定。** 判给**只限新增战斗代码**：`segSegDist2` 等新判定纯四则；既有城区/portal 判定不改（确定性门已 PASS，避免无谓回归）。
