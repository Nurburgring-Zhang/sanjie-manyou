# S02 · 三界空间与坐标（融合终版）

> 素材：V7《探索与地下》（地下/维度部分）× D2《三界空间与坐标》× `heavenFrame.ts` / `underworld.ts` / `world.ts` 实测。

## ① 代码现状（实测锚）

**天宫换算唯一真相源**：`src/sky/heavenFrame.ts` 常量五个——`HEAVEN_SCALE = 2.2`（`:11`）、`HEAVEN_BASE_Y = 196`（`:13`）、`HEAVEN_Y_MIN = 150`（`:15`）、`HEAVEN_LIFT = 1935`（`:17`）、`HEAVEN_BASE_LIFTED = 2131`（`:19`）；函数两个——`heavenY(y)`（`:22-24`）、`heavenPoint(x,y,z)`（`:27-29`，x/z ×2.2、y 走 heavenY）。均为纯函数，可在 Node 单测。

**地府**：`src/sky/underworld.ts:10` `export const UNDER = { y: -260, gateZ: -130, bridgeZ: -60 }`。地府地坪 −260，望乡台台面 −242（`UNDER.y + 18`）。**禁止把 −240 当地府基准去改 `UNDER.y`**——那会把十八狱环/丰都/阎罗殿整体抬 20m。

**玩家端地面判定**：`src/game/player.ts:234` `groundHeight(x,z,refY)`——`refY < -100` 直接返回 −260（`:235-237`）；`refY > 150 + HEAVEN_LIFT` 走天宫平台表 `PLATFORMS`（`:240` 起）；城区 `Math.hypot(x,z) < 5150` 走桥面/码头/0；城外走 `terrainHeight`。**该函数是纯解析式，不认识方块与造物**（P0-2 要改的核心）。

**POI 天宫点**：`src/city/layout.ts:169-176` 全部走 `heavenPoint`（`nantianmen` `heavenPoint(0,203.12,-80)`；`lingxiao` 现为 `heavenPoint(117.05,214.8,115.23)`——V13 卷所记「lingxiao POI 是抬升前遗留值 (14,236,250)」的缺陷**已修复**，卷内该条判据过时）。蟠桃赏赐交互点同样已修（勘误层：heavenPoint，实测 dy=0）。

**传送**：`src/game/player.ts:495-498` `PORTALS` 仅两向（人间 (470,0,24)⇄地府 (0,−260,−130)/(0,−260,−124)⇄(472,0,28)），无冷却无条件；回程落点与去程入口距 4.47m，靠 1.87m 余量维持不循环。图鉴传送 `World.teleport(key)` 在 `src/world.ts:1538`，`CAM_OFF` 表在 `world.ts:1527`（缺 key 落默认 `[12,7,16]`）。`isNight` 判定 `phase > 0.16 && phase < 0.86`（`world.ts:1284`）。

**世界尺度**：`TERRAIN_SIZE=62000`、`TERRAIN_SEG=300` ⇒ 地形格距 206.67m（V7 F1 实读 `src/world/terrain.ts:329`）；昆仑峰 h=3800 高于天宫台面 2131–2206（V7 §4.2 的空间矛盾，现状未解）。

## ② V 系设计要点（V7 卷：地下/维度部分）

V7 五条起手事实中与空间直接相关的三条：F1 地形高度场 62km/301×301 顶点，**12m 洞口只占 0.058 个网格单元，地形网格物理上表达不了洞口**；F3 三界垂直分层（人间 y≈0 / 天宫 y≈2150 / 地府 y=−260），「无限世界」只可能横向；F5 洞穴遗迹总面数预算 ≤0.3M 否则 12s 红线破。硬结论：**洞穴不是挖出来的，是另做一具几何再用结构物盖接缝**；加密地形到格距 6m 需 1.07 亿顶点，比全项目静态面还大三个数量级。维度边界：垂直分层 vs 水平无限的取舍落「垂直加层（地下预算另立）+ 横向有限」；地下的垂直预算单独列表，与天宫/地府互不挤占。三界互通：现状只有一组不对称门 + 开发者调试通道 `teleport()`；V7 设计两组合法门 + 一条单向秘境（`heavenGate` 泰山顶⇄南天门、`yinYangGate` 补冷却、`abyssGate` 天宫无底洞→地府枉死城单向、代价蟠桃 1、冷却 180s），并给五条 POI 兼容铁律（注册/走 heavenPoint/CAM_OFF 有偏移/落脚判据/探针独立手抄）。门与 `teleport()` 语义分开：门=玩法内移动（有代价有冷却），teleport=图鉴/复活/探针。

## ③ D 系设计要点（D2 卷）

D2 三句话坐标系：单位米、右手系、场景无全局缩放；天宫不是另一个场景，是同一场景里被抬高+放大的一层几何；地府是 y≈−260 处铺的一层几何。**三界是同一坐标系里的三个 y 带**，跨界只是一次 y 赋值或传送。层带表：地府 −320…−120（地面 −260.00）；人间 −2…+40（地面 −1.14…+0.28，水面 1.0）；天宫 2131…2360（地面 2142.1…2196.8）；云海顶面 2131.0（不可站立）。ADR-1 细则：`heavenY` 一次函数可逆（建议补导出 `heavenYInv()`）；`heavenPoint` 是等比缩放+平移的复合，不能用 4×4 矩阵替代；凌霄锚点 `LINGXIAO_ANCHOR.y = 233+1935 = 2168` 与 `heavenPoint(0,233,209) = (0,2212.4,459.8)` **不相等且都对**——前者是顶点变换链固定锚（世界口径 x/z），后者是设计点换算，混用会让凌霄殿漂 250m。五次坐标事故逐条给算式（神像低 21.8m、演员低 21.8m、POI 水平偏 96–180m、凌霄阈值差 3m 等）。五块沙盒落位（D3 阻塞项）：S1 西郊农事场 (−800,−0.90,150)、S2 东门货场 (700,−0.50,140)、S3 南岸窑场 (200,0.15,−210)、S4 天宫新云台 (−150,2153,0)、S5 地府西鬼市 (−200,−260,−150)，每块带六条判据（J1 净空/J2 高差 ≤0.6m/J3 避河按 `riverCenterZ` 函数算/J4 不在水面/J5 可达/J6 不压 POI）与射线取证；**中心 y 是地面标高，体素原点取 y_ground，沙盒 y 范围 [y_ground, y_ground+24]**。100m 生成区用载入期 `insertionMask` 索引，否决运行时射线（实测被否的路）。

**D2 补充**：ADR-1 记录的五次坐标事故（神像低 21.8m、演员低 21.8m、POI 水平偏 96–180m、凌霄阈值差 3m 等）每条都给了可复算算式；现有两道机检 `probe-heaven-convention` / `probe-heaven-transform-consistency` 有诚实边界（静态扫描覆盖不到运行时构造的点）。D2 §4 的 100m 生成区：运行时射线方案被实测否掉（成本与不确定性双高），必须载入期建 `insertionMask` 栅格；栅格三个数据源（烘焙几何/POI/水面），选址算法给三条硬性否定的判据化（压建筑/悬空/落水面中央）与降级链。S4 天宫·新云台的逐块论证特别注明：五条射线**无命中**（穿到 `bian_river` y=1）——天宫台面下的空域没有地面层，故必须新云桥或传送，五块中唯一不可步行到达。V7 §4.4 地下的垂直预算单独立账，与天宫/地府层带互不挤占；§4.3 的取舍结论是「垂直加层 + 横向有限」。

## ④ 冲突裁决

1. **地府基准 −260 vs −240。** 判给 **−260**（`underworld.ts:10` 实测 + 共享约束仲裁节原判）；−242 只是望乡台台面。三方一致，无分歧。
2. **lingxiao POI 缺陷（V13 卷判据）vs 现状已修。** 判给**现状**：`layout.ts:173` 已走 `heavenPoint(117.05,214.8,115.23)`；V13 §一.2 与其 A9「已知缺陷」条目作废，但「仪式点不挂 lingxiao、落点用 yaochi/jiangtai」的纪律保留。
3. **V7「天宫无传送门」vs 勘误层「P1-1 蟠桃赏赐交互点已修复」。** 判给**勘误层**：交互侧天宫点位已接 `heavenPoint` 且实测 dy=0；V7 的「开发者调试通道」论断对 `PORTALS`（确实只有阴阳界两向）仍成立——玩法意义上天宫仍无门，V7 §3.2 的三组门设计继续有效，归 S07。
4. **沙盒尺寸：V2 64×64×48m（0.5m 格）vs D2/D3 32×32×24m。** 判给 **D2/D3**：D2 的五块落位、射线取证、J1–J6 判据全部按 32×32×24 实测落地；V2 的 64×64×48 是路线 A 初版参数。可挖深度、矿脉账在 S03/S04 按 24m 重算。
5. **天宫低于昆仑（y 矛盾）。** V7 提出、D2 未裁。判给**维持现状 + 记录在案**：改昆仑或抬天宫都撞「一个实例都不许删」与已定基线；此矛盾按「设定层解释（仙山高于天阙）」处理，禁止动几何。
6. **`heavenYInv()` 未导出。** D2 建议、V 卷沉默。判给 **D2**：补导出逆函数，纯函数零风险，服务调试与落点反查。
